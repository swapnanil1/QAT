## Problem:

Solution A contains 10% acid by volume, and Solution B contains 30% acid by volume. In what ratio should Solution A be mixed with Solution B to obtain a mixture that contains 25% acid by volume?

(A) 1 : 2
(B) 2 : 1
(C) 1 : 3
(D) 3 : 1

## Solution:

**1. Identify the concentrations of the components and the desired mean concentration:**
   *   Concentration of Cheaper/Lower (Solution A) = C = 10% acid
   *   Concentration of Dearer/Higher (Solution B) = D = 30% acid
   *   Mean Concentration of Mixture = M = 25% acid

**2. Apply the Rule of Alligation:**
   We can directly use the percentage concentrations in the alligation rule.

   ```text
    Solution A (Lower %)        Solution B (Higher %)
         C = 10%                   D = 30%
           \                       /
            \                     /
              Mean % (M = 25%)
            /                     \
           /                       \
      (D - M) = 30 - 25         (M - C) = 25 - 10
          = 5                       = 15
          |                         |
          v                         v
   Ratio Part for Sol A        Ratio Part for Sol B
   ```
   
**3. Determine the ratio:**  
The ratio in which Solution A and Solution B should be mixed is given by:  
Ratio (A : B) = (D - M) : (M - C)  
Ratio (A : B) = 5 : 15

**4. Simplify the ratio:**  
Divide both parts by their GCD, which is 5:  
Ratio (A : B) = (5 / 5) : (15 / 5)  
Ratio (A : B) = 1 : 3
Therefore, Solution A and Solution B should be mixed in the ratio 1 : 3.

## Shortcut/Tip

- **Direct Application:** When dealing with concentrations (like percentages), the Alligation rule can be applied directly using the percentage values.
    
- **Consistency:** Ensure you are using the concentration of the same component (e.g., acid in this case) for all three values (C, D, M). You could also solve this using water concentrations (Solution A: 90% water, Solution B: 70% water, Mixture: 75% water). The resulting ratio (A:B) would be (75-70) : (90-75) = 5 : 15 = 1 : 3, which is the same. Choose whichever component seems easier.
    
- **Mean Value Check:** Verify that the desired mean concentration (25%) lies strictly between the concentrations of the two solutions being mixed (10% and 30%).
    
- **Ratio Order:** Remember that the result (D-M) corresponds to the quantity of the ingredient with concentration C, and (M-C) corresponds to the quantity of the ingredient with concentration D. So, the ratio A:B is (D-M) : (M-C).
