# Example: Two Successive Increases (Indirect Application)

Tags: #quant #percentages #successive_change #increase #example #tricky_question #geometry_application

Parent Concept: [[02 - Percentages/03 - Successive Percentage Change]]

## Problem

The length of a rectangular plot is increased by 20%. To achieve an overall increase of 50% in the plot's area, by what percentage must the width be increased?

## Analysis

This problem involves two percentage increases (one for length, one for width) whose combined effect results in a net percentage increase in the area. The area increase (50%) is the *result* of the successive/combined effects of the changes in dimensions.

Let:
*   Original Length = L
*   Original Width = W
*   Original Area = A = L * W
*   Percentage increase in Length = 20%
*   Percentage increase in Width = x% (This is what we need to find)
*   Net Percentage increase in Area = 50%

## Solution

1.  **Express New Dimensions and Area using Multiplication Factors:**
    *   New Length (L') = L * (1 + 20/100) = L * 1.20
    *   New Width (W') = W * (1 + x/100)
    *   New Area (A') = A * (1 + 50/100) = A * 1.50

2.  **Use the Area Formula:**
    New Area = New Length * New Width
    A' = L' * W'

3.  **Substitute the expressions from Step 1:**
    A * 1.50 = (L * 1.20) * (W * (1 + x/100))

4.  **Substitute Original Area (A = L * W):**
    (L * W) * 1.50 = (L * 1.20) * (W * (1 + x/100))

5.  **Simplify and Solve for the Width Factor (1 + x/100):**
    Cancel L and W from both sides:
    1.50 = 1.20 * (1 + x/100)
    Divide both sides by 1.20:
    (1 + x/100) = 1.50 / 1.20
    (1 + x/100) = 15 / 12
    (1 + x/100) = 5 / 4
    (1 + x/100) = 1.25

6.  **Find the percentage increase (x):**
    From `1 + x/100 = 1.25`, we get:
    x/100 = 1.25 - 1
    x/100 = 0.25
    x = 0.25 * 100
    x = 25

## Alternative using Net Change Formula (Less Intuitive Here)

Let `a` = % change in Length = +20
Let `b` = % change in Width = +x
Net % Change (Area) = `a + b + (a * b / 100)` = +50

50 = 20 + x + (20 * x / 100)
50 = 20 + x + (x / 5)
Subtract 20 from both sides:
30 = x + x/5
30 = (5x + x) / 5
30 = 6x / 5
Multiply both sides by 5:
150 = 6x
Divide by 6:
x = 150 / 6
x = 25

## Shortcut/Tip

Think in terms of factors:
Area Factor = Length Factor * Width Factor
1.50 = 1.20 * Width Factor
Width Factor = 1.50 / 1.20 = 5/4 = 1.25
Since Width Factor = `1 + x/100`, a factor of 1.25 corresponds to a 25% increase.

**Answer:** The width must be increased by 25%.
