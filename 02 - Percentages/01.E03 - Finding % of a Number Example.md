# Example: Finding Percentage of a Number

Tags: #quant #percentages #basic_concepts #example #percentage_of_number

Parent Concept: [[02 - Percentages/01 - Basic Concepts and Conversions]]

## Problem

A company has 2400 employees. 62.5% of the employees are males. 40% of the male employees and 50% of the female employees are graduates. How many employees are graduates?

## Solution

1.  **Calculate the number of male employees:**
    Number of Males = 62.5% of 2400
    *Shortcut:* 62.5% = 5/8
    Number of Males = (5/8) * 2400 = 5 * 300 = 1500 employees

2.  **Calculate the number of female employees:**
    Number of Females = Total Employees - Number of Males
    Number of Females = 2400 - 1500 = 900 employees
    *Alternatively:* Percentage of Females = 100% - 62.5% = 37.5% (or 3/8)
    Number of Females = 37.5% of 2400 = (3/8) * 2400 = 3 * 300 = 900 employees

3.  **Calculate the number of male graduates:**
    Male Graduates = 40% of Number of Males
    Male Graduates = 40% of 1500 = (40/100) * 1500 = 0.4 * 1500 = 600 employees
    *Alternatively (using fractions):* 40% = 2/5
    Male Graduates = (2/5) * 1500 = 2 * 300 = 600 employees

4.  **Calculate the number of female graduates:**
    Female Graduates = 50% of Number of Females
    Female Graduates = 50% of 900 = (1/2) * 900 = 450 employees

5.  **Calculate the total number of graduates:**
    Total Graduates = Male Graduates + Female Graduates
    Total Graduates = 600 + 450 = 1050 employees

## Shortcut/Tip

*   Use fractional equivalents (62.5% = 5/8, 37.5% = 3/8, 40% = 2/5, 50% = 1/2) for faster calculations.
*   Break down the problem into smaller, manageable steps.

**Answer:** There are 1050 graduate employees in the company.
