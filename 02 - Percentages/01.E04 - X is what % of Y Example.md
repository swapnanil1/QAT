# Example: Percentage to Fraction Conversion

Tags: #quant #percentages #basic_concepts #conversions #example #percentage_to_fraction

Parent Concept: [[02 - Percentages/01 - Basic Concepts and Conversions]]

## Problem

In an election between two candidates, one candidate secured 58% of the total valid votes. If the total valid votes were 7500, what fraction of the valid votes did the *other* candidate secure? Simplify the fraction.

## Solution

1.  **Find the percentage of votes for the other candidate:** If one candidate got 58%, the other candidate must have received the remaining percentage of the valid votes.
    Percentage for other candidate = 100% - 58% = 42%

2.  **Convert this percentage to a fraction:** Divide the percentage by 100.
    Fraction for other candidate = 42 / 100

3.  **Simplify the fraction:** Find the greatest common divisor (GCD) of the numerator and denominator and divide both by it. The GCD of 42 and 100 is 2.
    Simplified Fraction = 42 ÷ 2 / 100 ÷ 2 = 21 / 50

*(Note: The total number of votes (7500) was extra information not needed to find the fraction, which is a common distractor in aptitude questions.)*

## Shortcut/Tip

*   Directly work with the percentage for the other candidate (42%).
*   Write it as 42/100 and simplify immediately by dividing both by 2.

**Answer:** The other candidate secured 21/50 of the total valid votes.
