# Example: Calculating Percentage Decrease

Tags: #quant #percentages #percentage_change #decrease #example

Parent Concept: [[02 - Percentages/02 - Percentage Increase and Decrease]]

## Problem

Due to off-season, the price of a hotel room decreased from ₹3500 per night to ₹2800 per night. Find the percentage decrease in the price.

## Solution

1.  **Identify Original and New Values:**
    Original Value (Old Price) = ₹3500
    New Value (New Price) = ₹2800

2.  **Calculate the Decrease Amount:**
    Decrease Amount = Original Value - New Value
    Decrease Amount = ₹3500 - ₹2800 = ₹700

3.  **Apply the Percentage Decrease Formula:**
    Percentage Decrease = (Decrease Amount / Original Value) * 100 %
    Percentage Decrease = (700 / 3500) * 100 %

4.  **Calculate the Result:**
    Percentage Decrease = (7 / 35) * 100 %
    Percentage Decrease = (1 / 5) * 100 %
    *Shortcut:* Recognize 1/5 = 20%.
    Percentage Decrease = 20%

## Shortcut/Tip

*   Simplify the fraction (Decrease Amount / Original Value) first: 700 / 3500 = 7 / 35 = 1 / 5.
*   Convert the simplified fraction 1/5 to its percentage equivalent, which is 20%.

**Answer:** The price of the hotel room decreased by 20%.
