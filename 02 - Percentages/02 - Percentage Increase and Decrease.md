# 02 - Percentage Increase and Decrease

Understanding how quantities change in terms of percentage is crucial for many quantitative aptitude topics.

**Reference Concept:** [[02 - Percentages/01 - Basic Concepts and Conversions]]

## Percentage Change

Percentage change measures the difference between an original value and a new value, expressed as a percentage of the original value.

**General Formula:**
`Percentage Change = ((New Value - Original Value) / Original Value) * 100 %`
or
`Percentage Change = ((Change in Value) / Original Value) * 100 %`

*   **Positive result:** Indicates a percentage increase.
*   **Negative result:** Indicates a percentage decrease (usually stated as a positive percentage decrease, e.g., "a 10% decrease").

## Percentage Increase

This applies when the new value is greater than the original value.

**Formula:**
`Percentage Increase = ((New Value - Original Value) / Original Value) * 100 %`

**Calculating New Value after Increase:**
If a value `V` is increased by `x%`, the new value `V_new` is:
`V_new = V + (x/100) * V`
`V_new = V * (1 + x/100)`

**Shortcut (Multiplying Factor):**
The term `(1 + x/100)` is the multiplying factor for an increase.
*   10% increase -> Factor = (1 + 10/100) = 1.10
*   25% increase -> Factor = (1 + 25/100) = 1.25
*   `New Value = Original Value * Multiplying Factor (Increase)`

## Percentage Decrease

This applies when the new value is less than the original value.

**Formula:**
`Percentage Decrease = ((Original Value - New Value) / Original Value) * 100 %`

**Calculating New Value after Decrease:**
If a value `V` is decreased by `y%`, the new value `V_new` is:
`V_new = V - (y/100) * V`
`V_new = V * (1 - y/100)`

**Shortcut (Multiplying Factor):**
The term `(1 - y/100)` is the multiplying factor for a decrease.
*   10% decrease -> Factor = (1 - 10/100) = 0.90
*   20% decrease -> Factor = (1 - 20/100) = 0.80
*   `New Value = Original Value * Multiplying Factor (Decrease)`

## Finding the Original Value

Sometimes, the new value and the percentage change are given, and you need to find the original value.

**After an Increase:**
`Original Value = New Value / (1 + % Increase / 100)`
`Original Value = New Value / Multiplying Factor (Increase)`

**After a Decrease:**
`Original Value = New Value / (1 - % Decrease / 100)`
`Original Value = New Value / Multiplying Factor (Decrease)`

**Key Point:** Always calculate the percentage change with respect to the *original* value (unless the question specifically asks otherwise).
