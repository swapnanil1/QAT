# Example: Calculating Percentage Increase

Tags: #quant #percentages #percentage_change #increase #example

Parent Concept: [[02 - Percentages/02 - Percentage Increase and Decrease]]

## Problem

Ravi's monthly salary was ₹40,000. Due to a promotion, his salary increased to ₹46,000. By what percentage did his salary increase?

## Solution

1.  **Identify Original and New Values:**
    Original Value (Old Salary) = ₹40,000
    New Value (New Salary) = ₹46,000

2.  **Calculate the Increase Amount:**
    Increase Amount = New Value - Original Value
    Increase Amount = ₹46,000 - ₹40,000 = ₹6,000

3.  **Apply the Percentage Increase Formula:**
    Percentage Increase = (Increase Amount / Original Value) * 100 %
    Percentage Increase = (6,000 / 40,000) * 100 %

4.  **Calculate the Result:**
    Percentage Increase = (6 / 40) * 100 %
    Percentage Increase = (3 / 20) * 100 %
    *Shortcut:* Recognize 1/20 = 5%. So, 3/20 = 3 * 5% = 15%.
    *Alternatively:* (3 / 20) * 100 = 3 * 5 = 15%

## Shortcut/Tip

*   Simplify the fraction (Increase Amount / Original Value) before multiplying by 100.
    6000 / 40000 = 6 / 40 = 3 / 20
*   Convert the simplified fraction to a percentage. 3/20 is equivalent to 15%.

**Answer:** Ravi's salary increased by 15%.
