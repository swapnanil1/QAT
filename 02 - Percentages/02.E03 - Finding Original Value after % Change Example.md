# Example: Finding Original Value after % Change (Tricky)

Tags: #quant #percentages #percentage_change #original_value #example #tricky_question

Parent Concept: [[02 - Percentages/02 - Percentage Increase and Decrease]]

## Problem

A shopkeeper reduced the price of an article by 15%. By doing so, the total sales revenue from that article increased by 20%. What was the percentage effect on the number of articles sold?

## Analysis

This problem *seems* to be about finding an original price, but it actually uses the concepts of percentage change to relate price, quantity, and revenue. We need to find the *percentage change in quantity*.

Let:
*   Original Price = P
*   Original Quantity Sold = Q
*   Original Revenue = R = P * Q

After the changes:
*   New Price (P') = Price reduced by 15% = P * (1 - 15/100) = P * (1 - 0.15) = 0.85 * P
*   New Revenue (R') = Revenue increased by 20% = R * (1 + 20/100) = R * (1 + 0.20) = 1.20 * R
*   New Quantity Sold = Q' (This is what we need to find the % change for)

We know that New Revenue (R') = New Price (P') * New Quantity (Q').

## Solution

1.  **Set up the relationship:**
    R' = P' * Q'
    Substitute the expressions in terms of original values:
    1.20 * R = (0.85 * P) * Q'

2.  **Substitute Original Revenue (R = P * Q):**
    1.20 * (P * Q) = (0.85 * P) * Q'

3.  **Solve for the ratio Q'/Q:**
    The 'P' cancels out on both sides:
    1.20 * Q = 0.85 * Q'
    Q' / Q = 1.20 / 0.85

4.  **Simplify the ratio:**
    Multiply numerator and denominator by 100 to remove decimals:
    Q' / Q = 120 / 85
    Divide both by their greatest common divisor (5):
    Q' / Q = 24 / 17

5.  **Interpret the ratio:**
    This means the New Quantity (Q') is 24/17 times the Original Quantity (Q).
    Q' = (24 / 17) * Q

6.  **Calculate the Percentage Change in Quantity:**
    Percentage Change = [(New Quantity - Original Quantity) / Original Quantity] * 100 %
    Percentage Change = [(Q' - Q) / Q] * 100 %
    Percentage Change = [( (24/17)Q - Q ) / Q] * 100 %
    Factor out Q from the numerator:
    Percentage Change = [ Q * (24/17 - 1) / Q ] * 100 %
    Cancel Q:
    Percentage Change = (24/17 - 17/17) * 100 %
    Percentage Change = (7 / 17) * 100 %
    Percentage Change = 700 / 17 %

7.  **Calculate the final percentage (approximate if needed):**
    700 ÷ 17 ≈ 41.176...
    Percentage Increase ≈ 41.18 %

## Shortcut/Tip

*   Use the concept: Revenue = Price × Quantity.
*   Think in terms of multiplication factors:
    New Revenue = Original Revenue * 1.20
    New Price = Original Price * 0.85
    New Quantity = Original Quantity * X (where X is the multiplication factor for quantity)
*   Set up the equation: (Original Price * 0.85) * (Original Quantity * X) = (Original Price * Original Quantity) * 1.20
*   Cancel Original Price and Original Quantity:
    0.85 * X = 1.20
    X = 1.20 / 0.85 = 120 / 85 = 24 / 17
*   The factor X represents (1 + % change / 100).
    % change / 100 = X - 1 = (24/17) - 1 = 7/17
    % change = (7/17) * 100 = 700/17 % ≈ 41.18% (Increase)

**Answer:** The number of articles sold increased by 700/17 % or approximately 41.18%.
