# Example: Machine Depreciation (Variable Rates)

Tags: #quant #percentages #applications #depreciation #variable_rates #successive_change #example #tricky_question

Parent Concept: [[02 - Percentages/04 - Applications (Population, Depreciation)]]

## Problem

The value of a new machine is ₹1,20,000. Its value depreciates by 10% in the first year, 15% in the second year, and 20% in the third year. What will be the value of the machine after 3 years?

## Analysis

This problem involves successive percentage decreases (depreciation), but the rate of depreciation changes each year. Therefore, we cannot use the simple `V_n = V0 * (1 - R/100)^n` formula. Instead, we must apply the multiplication factor for each year's depreciation rate sequentially.

Let:
*   `V0` = Original Value = ₹1,20,000
*   `R1` = Depreciation rate in Year 1 = 10%
*   `R2` = Depreciation rate in Year 2 = 15%
*   `R3` = Depreciation rate in Year 3 = 20%
*   `V_3` = Value after 3 years = ?

We will use the formula for variable rates:
`V_n = V0 * (1 - R1/100) * (1 - R2/100) * (1 - R3/100) * ...`

## Solution

1.  **Identify the initial value and rates:**
    *   `V0 = 1,20,000`
    *   `R1 = 10%` => Factor1 = `1 - 10/100 = 1 - 0.10 = 0.90`
    *   `R2 = 15%` => Factor2 = `1 - 15/100 = 1 - 0.15 = 0.85`
    *   `R3 = 20%` => Factor3 = `1 - 20/100 = 1 - 0.20 = 0.80`

2.  **Apply the formula by multiplying the initial value by the successive factors:**
    *   `V_3 = V0 * Factor1 * Factor2 * Factor3`
    *   `V_3 = 1,20,000 * 0.90 * 0.85 * 0.80`

3.  **Calculate the result step-by-step or by multiplying factors first:**

    *   *Method 1: Step-by-step*
        *   Value after 1 year = `1,20,000 * 0.90 = 1,08,000`
        *   Value after 2 years = `1,08,000 * 0.85`
            *   `108000 * 0.85 = 108000 * (1 - 0.15) = 108000 - (108000 * 0.15)`
            *   `10% of 108000 = 10800`, `5% = 5400`, `15% = 10800 + 5400 = 16200`
            *   `108000 - 16200 = 91,800`
        *   Value after 3 years = `91,800 * 0.80` (Decrease by 20% or take 80%)
            *   `10% of 91800 = 9180`, `20% = 18360`
            *   `91800 - 18360 = 73,440`
            *   *Alternatively:* `91800 * 0.8 = 9180 * 8 = 73440`

    *   *Method 2: Multiply Factors First*
        *   Net Factor = `0.90 * 0.85 * 0.80`
        *   `0.90 * 0.80 = 0.72`
        *   Net Factor = `0.72 * 0.85`
            *   `0.72 * (0.8 + 0.05) = (0.72 * 0.8) + (0.72 * 0.05)`
            *   `= 0.576 + 0.036 = 0.612`
        *   `V_3 = V0 * Net Factor`
        *   `V_3 = 1,20,000 * 0.612`
        *   `V_3 = 12 * 10000 * 0.612 = 12 * 6120`
        *   `12 * 6120 = 12 * (6000 + 120) = 72000 + 1440 = 73,440`

## Shortcut/Tip

*   When rates are variable, always use the multiplication factor approach.
*   Multiplying the factors together first can sometimes simplify calculations if the numbers work out nicely, or if you only need the net percentage depreciation.
*   Breaking down multiplications (like `* 0.85` as `* (1 - 0.15)`) or using fractional equivalents (0.9 = 9/10, 0.85 = 17/20, 0.8 = 4/5) can be helpful.
    *   `V_3 = 120000 * (9/10) * (17/20) * (4/5)`
    *   `V_3 = 120000 * (9 * 17 * 4) / (10 * 20 * 5)`
    *   `V_3 = 120000 * 612 / 1000`
    *   `V_3 = 120 * 612 = 73,440`

**Answer:** The value of the machine after 3 years will be ₹73,440.
