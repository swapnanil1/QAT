# Example: Increase followed by Decrease (Order Matters)

Tags: #quant #percentages #successive_change #increase #decrease #order_matters #example #tricky_question

Parent Concept: [[02 - Percentages/03 - Successive Percentage Change]]

## Problem

The monthly salary of an employee was increased by 15% and subsequently decreased by 10%. The resulting salary was ₹45,900. What would the salary have been if it had *first* been decreased by 10% and *then* increased by 15%?

## Analysis

This problem requires two main steps:
1.  Find the original salary using the information from the first sequence of changes (Increase 15%, Decrease 10%).
2.  Calculate the final salary using the original salary found in step 1, but applying the changes in the reverse order (Decrease 10%, Increase 15%).
This highlights whether the order of successive percentage changes affects the final outcome.

## Solution

**Step 1: Find the Original Salary**

Let the Original Salary = S.

*   **First Change:** Increase by 15%.
    Salary after increase = S * (1 + 15/100) = S * 1.15
*   **Second Change:** Decrease by 10% (applied to the *new* salary).
    Final Salary = (S * 1.15) * (1 - 10/100)
    Final Salary = (S * 1.15) * 0.90
*   **Combine Factors:**
    Net Multiplication Factor = 1.15 * 0.90 = 1.035
    So, Final Salary = S * 1.035
*   **Use the Given Final Salary to Find S:**
    We know the Final Salary is ₹45,900.
    S * 1.035 = 45,900
    S = 45,900 / 1.035
    S = 45,900,000 / 1035  *(Multiply numerator and denominator by 1000)*

    *Simplification:*
    Divide both by 5: S = 9,180,000 / 207
    Recognize 207 is divisible by 9 (2+0+7=9): 207 / 9 = 23
    Divide 9,180,000 by 9: 9,180,000 / 9 = 1,020,000
    So, S = 1,020,000 / 23
    Now divide 1,020,000 by 23:
    1020 / 23 ≈ 44.34... Let's check the calculation 1.15 * 0.90 = 1.035 carefully.
    45900 / 1.035 = 44347.82... This seems unlikely for typical problems. Let's re-read.

    *Let's recheck the multiplication:* 1.15 * 0.9 = 1.035. Correct.
    *Let's check the division:* 45900 / 1.035.
    Maybe simpler numbers would be better? Let's try a simpler example first to confirm the principle.
    Start 100. +10% -> 110. -20% -> 110 * 0.8 = 88. Net Factor = 1.1 * 0.8 = 0.88. Original = 88 / 0.88 = 100.
    Reverse: Start 100. -20% -> 80. +10% -> 80 * 1.1 = 88. Net Factor = 0.8 * 1.1 = 0.88. Original = 88 / 0.88 = 100.

    Ah, the net multiplication factor IS the same regardless of order (multiplication is commutative: 1.15 * 0.90 = 0.90 * 1.15). The final result *should* be the same if starting from the same original value. The intermediate values differ, but the final value is the same.

    *Conclusion:* If the percentage changes are the same (+15% and -10%), the final salary will be the same regardless of the order in which they are applied.

    *Let's re-calculate to be sure the question implies the final answer is needed, even if it's the same.*
    Original Salary S = 45,900 / 1.035

**Step 2: Calculate Salary with Reversed Order**

Let the Original Salary = S (the value calculated above).

*   **First Change:** Decrease by 10%.
    Salary after decrease = S * (1 - 10/100) = S * 0.90
*   **Second Change:** Increase by 15% (applied to the *new* salary).
    New Final Salary = (S * 0.90) * (1 + 15/100)
    New Final Salary = (S * 0.90) * 1.15
*   **Combine Factors:**
    Net Multiplication Factor = 0.90 * 1.15 = 1.035
    New Final Salary = S * 1.035

*   **Compare:**
    The final salary in the first scenario was S * 1.035.
    The final salary in the second scenario is also S * 1.035.
    Since the original salary (S) is the same, and the net multiplication factor (1.035) is the same, the final salary must be the same.

## Shortcut/Tip

Recognize that the net effect of successive percentage changes depends on the product of their individual multiplication factors. Since multiplication is commutative (a * b = b * a), the order of the changes does not affect the *final* net multiplication factor or the final value, given the same starting value and the same set of percentage changes.

Therefore, without needing to calculate the original salary, we know the final salary would still be ₹45,900.

**Answer:** The salary would still be ₹45,900. The trick in this question is realizing the final result is independent of the order of the same percentage changes.
