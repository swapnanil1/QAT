# Example: Net Percentage Change Formula (Expenditure Scenario)

Tags: #quant #percentages #successive_change #net_change_formula #example #tricky_question #expenditure #application

Parent Concept: [[02 - Percentages/03 - Successive Percentage Change]]

## Problem

Due to a price hike, the price of petrol increased by 30%. By what percentage should a car owner reduce their petrol consumption so that their overall expenditure on petrol increases by only 10%?

## Analysis

This problem relates three quantities: Price, Consumption, and Expenditure, using the relationship:
**Expenditure = Price × Consumption**

This structure is analogous to Area = Length × Width. A change in Price and a change in Consumption combine successively to produce a net change in Expenditure.

We can model this using the successive percentage change concept:
*   Change 'a': Percentage change in Price = +30% (Increase)
*   Change 'b': Percentage change in Consumption = -x% (Unknown Decrease, this is what we need to find)
*   Net % Change: Percentage change in Expenditure = +10% (Net Increase)

We can apply the formula: `Net % Change = [ a + b + (a * b / 100) ] %` to find 'b' (which represents -x).

## Solution using Net % Change Formula

1.  **Identify the components:**
    *   `a = +30`
    *   `b = -x` (Let 'x' be the percentage reduction, so the change is negative)
    *   `Net % Change = +10`

2.  **Substitute into the formula:**
    `+10 = [ (+30) + (-x) + ((+30) * (-x) / 100) ]`

3.  **Simplify the equation:**
    `10 = 30 - x - (30x / 100)`
    `10 = 30 - x - (3x / 10)`

4.  **Solve for x:**
    Rearrange to group x terms:
    `x + 3x/10 = 30 - 10`
    Combine x terms with a common denominator (10):
    `(10x / 10) + (3x / 10) = 20`
    `13x / 10 = 20`
    Multiply by 10:
    `13x = 200`
    Isolate x:
    `x = 200 / 13`

5.  **Calculate the final percentage:**
    `x = 15.3846...`
    Rounding to two decimal places, x ≈ 15.38%

## Alternative Method (Using Factors)

Let Original Price = P, Original Consumption = C, Original Expenditure = E = P * C.

1.  Price increases by 30%: New Price (P') = P * (1 + 30/100) = P * 1.30
2.  Consumption reduces by x%: New Consumption (C') = C * (1 - x/100)
3.  Expenditure increases by 10%: New Expenditure (E') = E * (1 + 10/100) = E * 1.10

4.  Use the relationship E' = P' * C':
    E * 1.10 = (P * 1.30) * (C * (1 - x/100))

5.  Substitute E = P * C:
    (P * C) * 1.10 = (P * 1.30) * (C * (1 - x/100))

6.  Cancel P and C from both sides:
    1.10 = 1.30 * (1 - x/100)

7.  Solve for (1 - x/100):
    (1 - x/100) = 1.10 / 1.30
    (1 - x/100) = 11 / 13

8.  Solve for x:
    x/100 = 1 - (11 / 13)
    x/100 = (13 - 11) / 13
    x/100 = 2 / 13
    x = 200 / 13
    x ≈ 15.38%

## Shortcut/Tip

Recognize that Expenditure = Price × Consumption fits the successive change model. The formula `Net = a + b + ab/100` allows finding any one component if the other two are known. Remember that a reduction corresponds to a negative percentage change when using the formula. The factor method (Net Factor = Factor1 * Factor2) is also very reliable. Here: 1.10 = 1.30 * (Consumption Factor). Consumption Factor = 1.10/1.30 = 11/13. Since Factor = 1 - x/100, 11/13 = 1 - x/100 gives x/100 = 2/13 or x = 200/13.

**Answer:** The car owner should reduce consumption by **200/13 %** or approximately **15.38%**.
