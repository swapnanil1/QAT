# Probability of 'A and B' (Independent) Example

**Problem:**
A fair six-sided die is rolled and a fair coin is tossed simultaneously. What is the probability of getting a '4' on the die AND a 'Head' on the coin?

(A) 1/2
(B) 1/6
(C) 1/12
(D) 2/3

## Solution:

This problem asks for the probability of two specific outcomes occurring together from two separate, unrelated random experiments (rolling a die and tossing a coin). Since the outcome of the die roll does not affect the outcome of the coin toss, and vice versa, these events are independent. We use the Multiplication Rule for independent events: `P(A and B) = P(A) * P(B)`, as described in [[16 - Probability/02 - Probability Rules (Addition, Multiplication).md|the probability rules concept note]].

**Step 1: Define the Events**
Event A: Getting a '4' on the die roll.
Event B: Getting a 'Head' on the coin toss.

**Step 2: Calculate the Probability of Event A (P(A))**
The sample space for the die roll is `S_die = {1, 2, 3, 4, 5, 6}`, so `n(S_die) = 6`.
The favorable outcome for Event A is {4}, so `n(A) = 1`.
Using concepts from [[16 - Probability/01 - Basic Terminology (Event, Sample Space, P(E)).md|basic probability]]:
`P(A) = n(A) / n(S_die) = 1 / 6`.

**Step 3: Calculate the Probability of Event B (P(B))**
The sample space for the coin toss is `S_coin = {Head, Tail}`, so `n(S_coin) = 2`.
The favorable outcome for Event B is {Head}, so `n(B) = 1`.
`P(B) = n(B) / n(S_coin) = 1 / 2`.

**Step 4: Check for Independence**
The result of the die roll has no influence on the result of the coin toss. The events are independent.

**Step 5: Apply the Multiplication Rule for Independent Events**
The formula is `P(A and B) = P(A) * P(B)`.
`P(Getting a 4 AND a Head) = P(A) * P(B)`
`P(Getting a 4 AND a Head) = (1/6) * (1/2)`
`P(Getting a 4 AND a Head) = 1 / 12`

**Step 6: State the Final Probability**
The probability of getting a '4' on the die and a 'Head' on the coin is 1/12. This matches option (C).

## Shortcut/Tip
1.  **'AND' Keyword + Independence = Multiplication:** Recognize that "AND" implies the Multiplication Rule. If the events are independent (outcome of one doesn't affect the other), simply multiply their individual probabilities: `P(A and B) = P(A) * P(B)`.
2.  **Verify Independence:** Always quickly confirm if the events are truly independent. Simultaneous unrelated actions (die roll, coin toss) are usually independent. Drawing items *without replacement* is a key example of dependent events.
3.  **Distinguish 'AND' from 'OR':** Do not confuse the Multiplication Rule (for 'AND') with the Addition Rule (for 'OR'). Adding probabilities here (1/6 + 1/2 = 4/6 = 2/3 - Option D) would be incorrect.
4.  **Combined Sample Space (Alternative):** For simple cases, you could list the combined sample space: {1H, 1T, 2H, 2T, 3H, 3T, 4H, 4T, 5H, 5T, 6H, 6T}. Total outcomes `n(S) = 12`. The single favorable outcome is {4H}. `n(E) = 1`. Probability `P(E) = n(E)/n(S) = 1/12`. However, using the Multiplication Rule is generally faster and more scalable.
5.  **Distractor Analysis:** Option (B) 1/6 is just P(A). Option (A) 1/2 is just P(B). Option (D) 2/3 results from incorrectly adding P(A) and P(B).
