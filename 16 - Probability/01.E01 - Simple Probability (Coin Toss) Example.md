# Simple Probability (Coin Toss) Example

**Problem:**
Two fair coins are tossed simultaneously. What is the probability of getting exactly one head?

(A) 1/4
(B) 1/2
(C) 3/4
(D) 1

## Solution:

This problem requires finding the probability of a specific event when tossing two coins. We will use the basic definition of probability `P(E) = n(E) / n(S)` as outlined in [[16 - Probability/01 - Basic Terminology (Event, Sample Space, P(E)).md|the basic probability terminology note]].

**Step 1: Determine the Sample Space (S)**
When two fair coins are tossed, each coin can land as either Head (H) or Tail (T). The possible outcomes are pairs representing the result of the first coin and the second coin:
`S = {HH, HT, TH, TT}`
Where HH = Head on first, Head on second; HT = Head on first, Tail on second, etc.

**Step 2: Find the Total Number of Outcomes (n(S))**
The total number of possible outcomes in the sample space is 4.
`n(S) = 4`.

**Step 3: Identify the Event (E)**
The event of interest is getting *exactly* one head. We need to find the outcomes in the sample space that have only one H.
`E = {HT, TH}`

**Step 4: Find the Number of Favorable Outcomes (n(E))**
The number of outcomes favorable to event E (exactly one head) is 2.
`n(E) = 2`.

**Step 5: Calculate the Probability P(E)**
Using the formula `P(E) = n(E) / n(S)`:
`P(E) = 2 / 4`
`P(E) = 1/2`

**Step 6: State the Final Probability**
The probability of getting exactly one head when tossing two fair coins is 1/2. This matches option (B).

## Shortcut/Tip
1.  **List Outcomes Systematically:** For simple experiments like coin tosses or dice rolls, listing the entire sample space (`S`) is often the easiest way to ensure you don't miss any outcomes. Use a consistent order (e.g., HH, HT, TH, TT).
2.  **Identify 'Exactly':** Pay close attention to wording like "exactly," "at least," "at most." "Exactly one head" means {HT, TH}. "At least one head" would mean {HH, HT, TH} (`n(E)=3`, `P(E)=3/4`). "At most one head" would mean {HT, TH, TT} (`n(E)=3`, `P(E)=3/4`).
3.  **Basic Formula:** This example directly applies the fundamental definition `P(E) = n(E) / n(S)`.
4.  **Fair Coins:** The term "fair" implies that Head and Tail are equally likely outcomes for each coin toss (P(H) = P(T) = 1/2), making the combined outcomes (HH, HT, TH, TT) equally likely.
5.  **Distractor Analysis:** Option (A) 1/4 is the probability of a specific outcome like HH or TT. Option (C) 3/4 is the probability of getting "at least one head."
