# Drawing Cards Probability Example

**Problem:**
Two cards are drawn at random from a standard deck of 52 playing cards without replacement. What is the probability that both cards drawn are Kings?

(A) 1/13
(B) 1/221
(C) 1/26
(D) 1/17

## Solution:

This problem involves calculating the probability of selecting specific types of items (Kings) when drawing multiple items (cards) from a set without replacement. Since the order in which the two cards are drawn does not matter for the final outcome (having two Kings), we can use combinations to find the total possible outcomes and the favorable outcomes, as discussed in [[16 - Probability/03 - Problems on Cards, Balls, etc.md|the concept note on common probability scenarios]] and using [[15 - Permutations and Combinations/03 - Combination (Selection) Formula (nCr).md|the combination formula]].

**Method 1: Using Combinations**

**Step 1: Determine the Total Number of Outcomes (n(S))**
We are drawing 2 cards from a standard deck of 52. The total number of ways to choose 2 cards from 52 is `52C2`.
`n(S) = 52C2 = 52! / (2! * (52 - 2)!) = 52! / (2! * 50!)`
`n(S) = (52 * 51 * 50!) / ((2 * 1) * 50!)`
`n(S) = (52 * 51) / 2`
`n(S) = 26 * 51 = 1326`.

**Step 2: Determine the Number of Favorable Outcomes (n(E))**
The event (E) is drawing 2 Kings. There are 4 Kings in the deck. The number of ways to choose 2 Kings from the 4 available Kings is `4C2`.
`n(E) = 4C2 = 4! / (2! * (4 - 2)!) = 4! / (2! * 2!)`
`n(E) = (4 * 3 * 2!) / ((2 * 1) * 2!)`
`n(E) = (4 * 3) / 2`
`n(E) = 12 / 2 = 6`.

**Step 3: Calculate the Probability P(E)**
Using the formula `P(E) = n(E) / n(S)` from [[16 - Probability/01 - Basic Terminology (Event, Sample Space, P(E)).md|basic probability concepts]]:
`P(E) = 6 / 1326`
Simplify the fraction. Both numerator and denominator are divisible by 6:
`6 / 6 = 1`
`1326 / 6 = 221`
`P(E) = 1 / 221`.

**Method 2: Using Sequential Probability (Dependent Events)**

Consider the draws sequentially.
Event A: The first card drawn is a King.
Event B: The second card drawn is a King.
We want `P(A and B)`. Since the draws are without replacement, the events are dependent. Use the rule `P(A and B) = P(A) * P(B|A)` from [[16 - Probability/02 - Probability Rules (Addition, Multiplication).md|probability rules]].

**Step 1: Calculate P(A)**
`P(A) =` (Number of Kings) / (Total cards) = 4 / 52 = 1 / 13.

**Step 2: Calculate P(B|A)**
This is the probability the second card is a King *given* the first was a King. After drawing one King, there are 3 Kings left and 51 total cards remaining.
`P(B|A) =` (Remaining Kings) / (Remaining cards) = 3 / 51 = 1 / 17.

**Step 3: Calculate P(A and B)**
`P(Both Kings) = P(A) * P(B|A)`
`P(Both Kings) = (1 / 13) * (1 / 17)`
`P(Both Kings) = 1 / 221`.

**Step 4: State the Final Probability**
The probability that both cards drawn are Kings is 1/221. This matches option (B).

## Shortcut/Tip
1.  **Combinations for Hands:** When selecting a group of items (like a hand of cards) simultaneously or where the order doesn't matter, using combinations (`nCr`) for `n(S)` and `n(E)` is generally the most reliable method.
2.  **Sequential Probability:** For "without replacement" scenarios, considering sequential draws using conditional probability (`P(A and B) = P(A) * P(B|A)`) is often computationally simpler, especially if `nCr` calculations become large.
3.  **Deck Knowledge:** Know the structure of a 52-card deck (4 suits, 13 ranks, 4 of each rank).
4.  **Simplify Fractions:** Always simplify the final probability. Recognize common factors. `51 = 3 * 17`, `52 = 4 * 13`.
5.  **Common Errors:** Using permutations instead of combinations; calculation errors in combinations; incorrect calculation of conditional probability (e.g., forgetting to decrease both the number of favorable outcomes and the total number of items for the second draw). Option (D) 1/17 is `P(B|A)` only. Option (A) 1/13 is `P(A)` only.
