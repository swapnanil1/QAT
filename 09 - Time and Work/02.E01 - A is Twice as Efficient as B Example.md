# A is Twice as Efficient as B Example

**Problem:**

A is twice as efficient as B. Working together, they can complete a certain piece of work in 14 days. In how many days can A alone complete the same work?

(A) 18 days
(B) 21 days
(C) 28 days
(D) 42 days

## Solution:

This problem involves using the concept of efficiency ratios to determine individual times when the combined time is known. Refer to [[09 - Time and Work/02 - Efficiency Comparison.md]].

**Method 1: Using Efficiency Ratios and LCM Method**

1.  **Efficiency Ratio:** A is twice as efficient as B.
    `Eff_A : Eff_B = 2 : 1`.
    Let `Eff_A = 2` units/day and `Eff_B = 1` unit/day.

2.  **Combined Efficiency:** When working together, their combined efficiency is `Eff_A+B = Eff_A + Eff_B = 2 + 1 = 3` units/day.

3.  **Calculate Total Work:** We know they complete the work together in 14 days.
    Total Work = Combined Efficiency * Time Taken Together
    Total Work = 3 units/day * 14 days = 42 units.

4.  **Calculate Time Taken by A Alone:**
    Time Taken by A = Total Work / Efficiency of A
    Time Taken by A = 42 units / 2 units/day = 21 days.

So, A alone can complete the work in 21 days. This matches option (B).

**Method 2: Using Time Ratios**

1.  **Efficiency Ratio:** `Eff_A : Eff_B = 2 : 1`.
2.  **Time Ratio:** Since Time is inversely proportional to Efficiency, the ratio of time taken is:
    `Time_A : Time_B = 1 : 2`.
    Let the time taken by A be `k` days and the time taken by B be `2k` days.

3.  **Use the Combined Work Formula:** Time(A+B) = `(Time(A) * Time(B)) / (Time(A) + Time(B))`
    We are given Time(A+B) = 14 days.
    `14 = (k * 2k) / (k + 2k)`
    `14 = (2k^2) / (3k)`
    `14 = 2k / 3` (Assuming k ≠ 0)

4.  **Solve for k:**
    `14 * 3 = 2k`
    `42 = 2k`
    `k = 21`

5.  **Find Time Taken by A:**
    Time Taken by A = `k` = 21 days.
    (Time Taken by B = `2k` = 42 days, which matches option D as a distractor).

The time taken by A alone is 21 days.

## Shortcut/Tip

1.  Establish the ratios: Eff(A):Eff(B) = 2:1 => Time(A):Time(B) = 1:2.
2.  Let Efficiencies be 2 and 1. Combined efficiency = 3.
3.  Total Work = Combined Eff * Time Together = 3 * 14 = 42 units.
4.  Time(A) = Total Work / Eff(A) = 42 / 2 = 21 days.

Alternatively, using the formula shortcut with time ratios:
1.  Time(A) = k, Time(B) = 2k.
2.  `Time(A+B) = (k * 2k) / (k + 2k) = 2k/3`.
3.  `14 = 2k/3` => `k = 21`.
4.  Time(A) = k = 21 days.

Be careful not to confuse the time taken by A (21 days) with the time taken by B (42 days), as both might be options. Read the question carefully to see which one is asked.
