# Efficiency Comparison

**Definition:**

In the context of Time and Work, **Efficiency** refers to the rate at which work is done by an individual or a group. It's essentially the amount of work completed per unit of time (e.g., work done per day, per hour).
`Efficiency = Work Done / Time Taken`

**Key Relationship:**

The most crucial relationship to understand is the **inverse proportionality between Efficiency and Time** required to complete a fixed amount of work:
`Efficiency ∝ 1 / Time` (assuming Work is constant)

This means:
*   If someone is more efficient, they will take less time to complete the same work.
*   If someone is less efficient, they will take more time to complete the same work.
*   If the ratio of efficiencies of A and B is `a : b`, then the ratio of the time taken by them to complete the same work will be `b : a`.

**Comparing Efficiencies:**

Efficiency comparisons are often stated in problems in various ways:

1.  **Ratio:** "A is twice as efficient as B." This means `Eff_A / Eff_B = 2 / 1`. The ratio of efficiencies is A : B = 2 : 1. Consequently, the ratio of time taken is Time_A : Time_B = 1 : 2.
2.  **Percentage:** "A is 20% more efficient than B." This means `Eff_A = Eff_B + 0.20 * Eff_B = 1.20 * Eff_B`. The ratio of efficiencies is A : B = 1.20 : 1 = 120 : 100 = 6 : 5. The ratio of times taken is Time_A : Time_B = 5 : 6.
3.  **Percentage (Less):** "A is 25% less efficient than B." This means `Eff_A = Eff_B - 0.25 * Eff_B = 0.75 * Eff_B`. The ratio of efficiencies is A : B = 0.75 : 1 = 75 : 100 = 3 : 4. The ratio of times taken is Time_A : Time_B = 4 : 3.

**Using Efficiency Ratios in Problem Solving:**

1.  **Determine the Efficiency Ratio:** Convert the statement (ratio, percentage) into a simple integer ratio of efficiencies (e.g., A : B = 2 : 3).
2.  **Determine the Time Ratio:** Invert the efficiency ratio to get the ratio of times taken (e.g., Time_A : Time_B = 3 : 2).
3.  **Relate to Given Time:** Use any given time value (for an individual or group) to find the value of one 'part' in the ratio.
4.  **Calculate Unknown Times/Efficiencies:** Use the value of the 'part' to find the required time or efficiency.
5.  **Combine with LCM Method:** Efficiency ratios can be directly used in the LCM method. If A : B = 2 : 3, you can assume their efficiencies are 2 units/day and 3 units/day respectively. Then, if one person's time is known, you can calculate the Total Work (`Total Work = Time * Efficiency`).

**Example Application:**

If A is twice as efficient as B, and A takes 10 days to complete a work, how long will B take?
*   Efficiency Ratio (A:B) = 2:1
*   Time Ratio (A:B) = 1:2
*   Let times be `1k` and `2k`.
*   Time(A) = `1k = 10` days. So, `k = 10`.
*   Time(B) = `2k = 2 * 10 = 20` days.
