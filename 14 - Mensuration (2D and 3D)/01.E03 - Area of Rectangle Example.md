# Area of Rectangle Example

**Problem:**
The perimeter of a rectangle is 34 cm and the length of its diagonal is 13 cm. Find the area of the rectangle.

(A) 60 cm²
(B) 120 cm²
(C) 55 cm²
(D) 110.5 cm²

## Solution:

This problem requires using the formulas for the perimeter and diagonal of a rectangle to find its area. The diagonal formula involves the Pythagorean theorem, and relating these quantities often uses algebraic identities. The basic rectangle formulas are in [[14 - Mensuration (2D and 3D)/01 - 2D Shapes Area and Perimeter (Triangle, Square, Rectangle, Circle).md|the 2D shapes concept note]].

**Step 1: Identify Given Information and Goal**
Given: Perimeter (P) = 34 cm, Diagonal (d) = 13 cm.
Goal: Find the Area (A) of the rectangle.
Let the length be `l` and the breadth be `b`.

**Step 2: Use the Perimeter Formula**
The formula for perimeter is `P = 2 * (l + b)`.
Substitute the given value:
34 = 2 * (`l + b`)
Divide by 2:
`l + b = 34 / 2`
`l + b = 17`  --- (Equation 1)

**Step 3: Use the Diagonal Formula (Pythagoras Theorem)**
The diagonal splits the rectangle into two right-angled triangles. Using [[13 - Geometry/02 - Triangles (Properties, Congruence, Similarity).md|Pythagoras theorem]], `d^2 = l^2 + b^2`.
Substitute the given value:
`13^2 = l^2 + b^2`
`169 = l^2 + b^2` --- (Equation 2)

**Step 4: Relate the Equations to Find the Area**
The area of the rectangle is `A = l * b`.
We can use the algebraic identity `(l + b)^2 = l^2 + b^2 + 2 * l * b`. This identity is covered in [[12 - Algebra/01 - Basic Algebraic Identities.md|basic algebraic identities]].
Substitute the values from Equation 1 and Equation 2 into the identity:
`(17)^2 = (169) + 2 * (l * b)`
289 = 169 + 2 * `A` (since `A = l * b`)

**Step 5: Solve for the Area (A)**
Rearrange the equation to find `A`:
2 * `A` = 289 - 169
2 * `A` = 120
`A = 120 / 2`
`A = 60`

**Step 6: State the Final Area**
The area of the rectangle is 60 cm². This matches option (A).

*(Self-check: If A=60 and l+b=17, are there integers l, b? Yes, l=12, b=5 satisfy both: 12+5=17 and 12*5=60. Check diagonal: 12² + 5² = 144 + 25 = 169 = 13². Dimensions are consistent.)*

## Shortcut/Tip
1.  **Recognize the Pattern:** Problems giving perimeter and diagonal of a rectangle frequently require using the identity `(l + b)^2 = l^2 + b^2 + 2lb` to efficiently find the area (`lb`).
2.  **Direct Formula:** Mentally combine the steps: Find `(l+b)` from perimeter (`P/2`). Find `l^2+b^2` from diagonal (`d^2`). Then directly calculate Area `A = [ (l+b)^2 - (l^2+b^2) ] / 2`. In this case: `A = [ (17)^2 - (13)^2 ] / 2 = [289 - 169] / 2 = 120 / 2 = 60`. This avoids writing intermediate equations.
3.  **Pythagorean Triples:** Recognize that a diagonal of 13 cm often corresponds to a Pythagorean triple (5, 12, 13). Check if sides 5 and 12 fit the perimeter: `2 * (5 + 12) = 2 * 17 = 34`. Yes, they do. Therefore, the area must be `l * b = 5 * 12 = 60`. This is the fastest method if you spot the triple.
4.  **Common Mistake:** A common error is forgetting the factor of 2 in the identity `(l+b)^2 = l^2+b^2 + 2A`. If you mistakenly calculate `A = (l+b)^2 - (l^2+b^2)`, you would get `A = 289 - 169 = 120`, leading to the incorrect option (B). Always remember the `2A`.
5.  **Algebraic Identity is Key:** Avoid solving for `l` and `b` individually using substitution, as it leads to a quadratic equation (`l * (17-l) = 60` => `17l - l^2 = 60` => `l^2 - 17l + 60 = 0`), which takes more time than using the identity.
