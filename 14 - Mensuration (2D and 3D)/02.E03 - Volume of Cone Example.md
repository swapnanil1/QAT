# Volume of Cone Example

**Problem:**
A right circular cone has a height of 24 cm and a radius of 7 cm. Find its volume. (Use `pi = 22/7`)

(A) 1232 cm³
(B) 3696 cm³
(C) 616 cm³
(D) 1848 cm³

## Solution:

This problem requires the direct application of the volume formula for a right circular cone, using the given height and radius. The formula is provided in [[14 - Mensuration (2D and 3D)/02 - 3D Shapes Surface Area and Volume (Cube, Cuboid, Cylinder, Cone, Sphere).md|the concept note on 3D shapes]].

**Step 1: Identify Given Information and Goal**
Given: Height (h) = 24 cm, Radius (r) = 7 cm. Use `pi = 22/7`.
Goal: Find the Volume (V) of the cone.

**Step 2: Apply the Cone Volume Formula**
The formula for the volume of a cone is `V = (1/3) * pi * r^2 * h`.
Substitute the given values:
`V = (1/3) * (22/7) * (7)^2 * 24`
`V = (1/3) * (22/7) * 49 * 24`

**Step 3: Simplify and Calculate the Volume**
Perform the multiplication, simplifying where possible:
Cancel the 7 in the denominator with one 7 from `r^2 = 49`: `49 / 7 = 7`.
Cancel the 3 in the denominator with the height 24: `24 / 3 = 8`.
The expression becomes:
`V = 22 * 7 * 8`
`V = 154 * 8`
`V = 1232`

**Step 4: State the Final Volume**
The volume of the cone is 1232 cm³. This matches option (A).

## Shortcut/Tip
1.  **Direct Formula:** This is a straightforward application of the volume formula `V = (1/3) * pi * r^2 * h`. Ensure you have memorized it correctly.
2.  **The Crucial 1/3:** A very common mistake is forgetting the `(1/3)` factor, essentially calculating the volume of a cylinder with the same base and height. If you forget the `1/3`, you would get `pi * r^2 * h = (22/7) * 49 * 24 = 22 * 7 * 24 = 154 * 24 = 3696` cm³, which corresponds to distractor (B). Always double-check the `1/3` for cones (and pyramids).
3.  **Simplify Before Multiplying:** Cancel common factors early (like `49/7 = 7` and `24/3 = 8`). This keeps the numbers smaller and reduces calculation errors compared to multiplying `22 * 49 * 24` first and then dividing by `(3 * 7 = 21)`.
4.  **Slant Height Check:** Note that the slant height (`l`) was not needed for the volume calculation. If surface area was required, you would need to calculate `l = sqrt(r^2 + h^2) = sqrt(7^2 + 24^2) = sqrt(49 + 576) = sqrt(625) = 25` cm, remembering the connection to [[13 - Geometry/02 - Triangles (Properties, Congruence, Similarity).md|Pythagoras theorem]].
5.  **Units:** Volume is always in cubic units (cm³ in this case). Check that the answer options have the correct units.
