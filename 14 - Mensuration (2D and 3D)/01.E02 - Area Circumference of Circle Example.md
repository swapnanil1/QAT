# Area Circumference of Circle Example

**Problem:**
The circumference of a circular park is 176 meters. Find the area of the park. (Use `pi = 22/7`)

(A) 1848 m²
(B) 2156 m²
(C) 2464 m²
(D) 2772 m²

## Solution:

This problem requires us to first find the radius of the circle using the given circumference and then use that radius to calculate the area, applying the formulas listed in [[14 - Mensuration (2D and 3D)/01 - 2D Shapes Area and Perimeter (Triangle, Square, Rectangle, Circle).md|the concept note for 2D shapes]].

**Step 1: Identify Given Information and Goal**
Given: Circumference (C) = 176 m.
Goal: Find the Area (A) of the park.
We will use `pi = 22/7`.

**Step 2: Use the Circumference Formula to Find the Radius (r)**
The formula for circumference is `C = 2 * pi * r`.
Substitute the given values:
176 = 2 * (22/7) * `r`
176 = (44/7) * `r`

**Step 3: Solve for the Radius (r)**
Rearrange the equation to isolate `r`:
`r = 176 * (7 / 44)`
Divide 176 by 44: 176 / 44 = 4.
`r = 4 * 7`
`r = 28` meters

**Step 4: Use the Radius to Calculate the Area (A)**
The formula for the area of a circle is `A = pi * r^2`.
Substitute the value of `r` and `pi`:
`A = (22/7) * (28)^2`
`A = (22/7) * (28 * 28)`
Divide one 28 by 7: 28 / 7 = 4.
`A = 22 * 4 * 28`
`A = 88 * 28`

Calculate the final area:
88 * 28 = 88 * (30 - 2) = (88 * 30) - (88 * 2) = 2640 - 176 = 2464.
`A = 2464` square meters.

**Step 5: State the Area**
The area of the circular park is 2464 m². This matches option (C).

## Shortcut/Tip
1.  **Relate C and A:** Understand that both Circumference (`C = 2 * pi * r`) and Area (`A = pi * r^2`) depend on the radius (`r`). Problems often give one to find the other.
2.  **Isolate 'r' carefully:** When solving `C = (44/7) * r` for `r`, remember to multiply by the reciprocal `(7/44)`, not `(44/7)`. `r = C * (7/44)`.
3.  **Calculation Strategy:** When calculating `A = (22/7) * 28 * 28`, simplify the division `(28/7 = 4)` *before* multiplying large numbers. Then, calculate `22 * 4 * 28 = 88 * 28`. Using distributive property `88 * (30 - 2)` can sometimes be faster than direct multiplication.
4.  **Units:** Remember Circumference is in linear units (m), radius is in linear units (m), and Area is in square units (m²). Ensure the final answer has the correct units.
5.  **Pi Value:** Always use the value of `pi` specified in the question (often 22/7 for easier calculation with multiples of 7, or sometimes 3.14). If not specified, 22/7 is usually preferred in competitive exams unless decimals are involved.
