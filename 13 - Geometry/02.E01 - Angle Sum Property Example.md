# Angle Sum Property Example

**Problem:**
In triangle ABC, angle A is `x°`, angle B is `(2x - 20)°`, and angle C is `(x + 40)°`. Find the measure of angle B.

(A) 30°
(B) 40°
(C) 60°
(D) 80°

## Solution:

This problem requires finding the measure of an angle in a triangle using the Angle Sum Property, which states that the sum of the interior angles of any triangle is always 180°, as mentioned in [[13 - Geometry/02 - Triangles (Properties, Congruence, Similarity).md]].

**Step 1: Identify the Angles**
Angle A = `x°`
Angle B = `(2x - 20)°`
Angle C = `(x + 40)°`

**Step 2: Apply the Angle Sum Property**
The sum of the angles must equal 180°:
Angle A + Angle B + Angle C = 180°
`x + (2x - 20) + (x + 40) = 180`

**Step 3: Solve the Linear Equation for x**
Combine like terms on the left side:
`(x + 2x + x) + (-20 + 40) = 180`
`4x + 20 = 180`

Subtract 20 from both sides:
`4x = 180 - 20`
`4x = 160`

Divide both sides by 4:
`x = 160 / 4`
`x = 40`

**Step 4: Calculate the Measure of Angle B**
The problem asks for the measure of angle B, which is given by the expression `(2x - 20)°`.
Substitute the value `x = 40` into this expression:
Angle B = `2*(40) - 20`
Angle B = 80 - 20
Angle B = 60°

The measure of angle B is 60°. This matches option (C).

*(Self-check: If x=40, Angle A = 40°, Angle B = 60°, Angle C = 40 + 40 = 80°. Sum = 40 + 60 + 80 = 180°. Correct.)*

## Shortcut/Tip
1.  **Core Property:** The fundamental step is recalling and applying the Angle Sum Property (`A + B + C = 180°`).
2.  **Set Up Equation:** Correctly translate the angle expressions into the sum equation.
3.  **Solve for x:** Solve the resulting [[12 - Algebra/02 - Linear Equations (One Two Variables).md|linear equation]] accurately. Watch for sign errors when combining terms.
4.  **Answer the Question:** Double-check what the question asks for. It asks for Angle B, not the value of `x`. A common mistake is to stop after finding `x` (which is 40, matching option B, a distractor). Always substitute `x` back into the required angle expression.
