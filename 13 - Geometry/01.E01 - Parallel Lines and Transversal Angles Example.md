# Parallel Lines and Transversal Angles Example

**Problem:**
In the figure below, line `l` is parallel to line `m` (`l || m`), and line `t` is a transversal. If the angle marked `(2x + 10)°` and the angle marked `(3x - 25)°` are given as shown, find the value of `x`.

**(Imagine a diagram showing two parallel horizontal lines `l` and `m` cut by a transversal `t`. The upper-left interior angle is marked `(2x + 10)°`. The lower-right interior angle is marked `(3x - 25)°`.)**

(A) 25
(B) 30
(C) 35
(D) 40

## Solution:

This problem involves finding the value of `x` using the properties of angles formed when a transversal intersects parallel lines, as defined in [[13 - Geometry/01 - Lines and Angles.md]].

**Step 1: Identify the Relationship Between the Angles**
The angle marked `(2x + 10)°` and the angle marked `(3x - 25)°` are located between the parallel lines `l` and `m` and on opposite sides of the transversal `t`. These are **Alternate Interior Angles**.

**Step 2: Apply the Property of Alternate Interior Angles**
According to the properties of parallel lines, alternate interior angles are equal.
Therefore, we can set the expressions for these angles equal to each other:
`2x + 10 = 3x - 25`

**Step 3: Solve the Linear Equation for x**
Rearrange the equation to group `x` terms on one side and constant terms on the other.
Subtract `2x` from both sides:
`10 = 3x - 2x - 25`
`10 = x - 25`

Add 25 to both sides:
`10 + 25 = x`
`35 = x`

**Step 4: State the Value of x**
The value of `x` is 35. This matches option (C).

*(Self-check: If x=35, the first angle is 2*(35) + 10 = 70 + 10 = 80°. The second angle is 3*(35) - 25 = 105 - 25 = 80°. Since both angles are equal (80°), the value x=35 is correct.)*

## Shortcut/Tip
1.  **Identify Angle Pair:** Quickly determine the relationship between the given angles (Alternate Interior, Corresponding, Consecutive Interior, Vertically Opposite, etc.).
2.  **Apply Property:** Recall the correct property (Equal or Supplementary). Alternate Interior angles are equal.
3.  **Set Up Equation:** Form the linear equation based on the property (`Angle1 = Angle2` or `Angle1 + Angle2 = 180`).
4.  **Solve Carefully:** Solve the resulting [[12 - Algebra/02 - Linear Equations (One Two Variables).md|linear equation]], paying attention to signs during rearrangement.
5.  **Common Mistake:** Confusing alternate interior angles (equal) with consecutive interior angles (supplementary). If mistakenly set as supplementary: `(2x + 10) + (3x - 25) = 180` => `5x - 15 = 180` => `5x = 195` => `x = 39` (close to option D, illustrating a potential distractor).
