## Problem:

The salaries of four colleagues A, B, C, and D are related as follows: The ratio of A's salary to B's salary is 2 : 3. The ratio of B's salary to C's salary is 4 : 5. The ratio of C's salary to D's salary is 6 : 7. If the difference between D's salary and A's salary is ₹3800, what is B's salary?

(A) ₹ 3200
(B) ₹ 4800
(C) ₹ 6000
(D) ₹ 7000

## Solution:

**1. State the given ratios:**
   `A : B = 2 : 3`
   `B : C = 4 : 5`
   `C : D = 6 : 7`

**2. Combine the ratios to find A : B : C : D:**
   We can use the shortcut method:
   `A : B = 2 : 3`
   `B : C =     4 : 5`
   `C : D =         6 : 7`
   -----------------------
   Calculate the components:
   *   `A = 2 * 4 * 6 = 48`
   *   `B = 3 * 4 * 6 = 72` (Start with B's value '3', multiply by C's antecedent '4', D's antecedent '6')
   *   `C = 3 * 5 * 6 = 90` (Start with B's value '3', use C's consequent '5', D's antecedent '6')
   *   `D = 3 * 5 * 7 = 105` (Start with B's value '3', use C's consequent '5', D's consequent '7')

   So, the combined ratio `A : B : C : D = 48 : 72 : 90 : 105`.

**3. Simplify the combined ratio:**
   Find the Greatest Common Divisor (GCD) of 48, 72, 90, and 105.
   All numbers are divisible by 3.
   `48 / 3 = 16`
   `72 / 3 = 24`
   `90 / 3 = 30`
   `105 / 3 = 35`
   The GCD is 3. (16, 24, 30, 35 have no further common factors).
   The simplified ratio `A : B : C : D = 16 : 24 : 30 : 35`.

**4. Use the given difference information:**
   Difference between D's salary and A's salary = ₹3800.
   Calculate the difference in the corresponding ratio parts:
   Difference in parts = D parts - A parts = 35 - 16 = 19 parts.

**5. Find the value of one ratio part:**
   The difference of 19 parts corresponds to ₹3800.
   Value of 1 part = Total Difference / Difference in Parts
   Value of 1 part = 3800 / 19
   Value of 1 part = ₹ 200.

**6. Calculate B's salary:**
   B's salary corresponds to 24 parts in the simplified ratio.
   B's salary = B's parts * Value of 1 part
   B's salary = 24 * 200 = ₹ 4800.

Therefore, B's salary is ₹ 4800.

## Shortcut/Tip

*   **Pattern Recognition:** Memorize or quickly derive the pattern for combining multiple ratios (A=ace, B=bce, C=bde, D=bdf for A:B=a:b, B:C=c:d, C:D=e:f).
*   **Simplify Early (If possible):** While we simplified the final combined ratio, sometimes you can simplify intermediate ratios if applicable, but be cautious not to disrupt the linking terms. Simplifying the final combined ratio is usually safer and sufficient.
*   **Use the Difference Directly:** Similar to the previous example, calculate the difference in ratio parts (D-A = 35-16=19) and equate it to the given monetary difference (₹3800) to find the value per part. This avoids calculating all individual salaries.
*   **Check Calculation:** Ensure the multiplication pattern for combining ratios is applied correctly. A common mistake is picking the wrong terms for B and C. Double-check the GCD calculation for simplification.
