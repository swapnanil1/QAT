## Problem:

A bag contains ₹1 coins, 50 paise coins, and 25 paise coins. The ratio of the *number* of these coins is 5 : 6 : 8, respectively. If the total value of the money in the bag is ₹ 420, find the total number of 50 paise coins.

(A) 210
(B) 240
(C) 252
(D) 280

## Solution:

**1. Define variables based on the ratio of the number of coins:**
   Let the ratio of the number of ₹1, 50p, and 25p coins be `5 : 6 : 8`.
   Let the actual number of ₹1 coins be `5x`.
   Let the actual number of 50p coins be `6x`.
   Let the actual number of 25p coins be `8x`.

**2. Convert all monetary values to a consistent unit (Paise):**
   *   Value of ₹1 coin = 100 paise
   *   Value of 50p coin = 50 paise
   *   Value of 25p coin = 25 paise
   *   Total value in the bag = ₹ 420 = 420 * 100 = 42000 paise.

**3. Calculate the total value contributed by each type of coin in terms of `x`:**
   *   Value from ₹1 coins = (Number of ₹1 coins) * (Value per ₹1 coin) = `5x * 100 = 500x` paise.
   *   Value from 50p coins = (Number of 50p coins) * (Value per 50p coin) = `6x * 50 = 300x` paise.
   *   Value from 25p coins = (Number of 25p coins) * (Value per 25p coin) = `8x * 25 = 200x` paise.

**4. Formulate the equation for the total value:**
   Total Value = Value from ₹1 coins + Value from 50p coins + Value from 25p coins
   `42000 = 500x + 300x + 200x`
   `42000 = 1000x`

**5. Solve for `x`:**
   `x = 42000 / 1000`
   `x = 42`

**6. Calculate the required number of 50 paise coins:**
   Number of 50p coins = `6x`
   Number of 50p coins = 6 * 42
   Number of 50p coins = 252.

Therefore, there are 252 coins of 50 paise denomination.

## Shortcut/Tip

*   **Unit Consistency:** Always convert denominations and total value to the same unit (Paise is often easier to avoid fractions/decimals). Forgetting this is a very common error.
*   **Ratio Type:** Double-check if the given ratio is for the *number* of coins (as here) or the *value* contributed by each type. The approach changes significantly. If the ratio of *values* was 5:6:8, the setup would be `5y + 6y + 8y = 420` (working in Rupees directly might be easier then), solve for `y`, find the value of 50p coins (`6y`), and then divide by the value of a 50p coin (0.50 Rupees) to get the number.
*   **Value Calculation:** Ensure you multiply the *number* of coins (`nx`) by the *value per coin* (`v`) to get the total value contributed (`nx * v`).
*   **Estimation Check:** After finding `x=42`:
    *   Number of ₹1 coins = 5*42 = 210 (Value ₹210)
    *   Number of 50p coins = 6*42 = 252 (Value ₹126)
    *   Number of 25p coins = 8*42 = 336 (Value ₹84)
    *   Total Value = 210 + 126 + 84 = ₹ 420. Matches the given total.
