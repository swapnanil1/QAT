# Proportion Concepts (Fourth, Third, Mean)

#quant #ratio_and_proportion #proportion_concepts #formula

## Definition

An equality of two ratios is called a **proportion**. If the ratio `a : b` is equal to the ratio `c : d`, then `a, b, c, d` are said to be in proportion. This is written as:

`a : b :: c : d` or `a/b = c/d`

Here:
*   `a` and `d` are called the **extremes** (outer terms).
*   `b` and `c` are called the **means** (middle terms).

**Fundamental Property:** In a proportion, the product of the extremes is equal to the product of the means.
`a * d = b * c`

## Types of Proportionals

1.  **Fourth Proportional:**
    *   If `a : b :: c : x`, then `x` is called the fourth proportional to `a, b, c`.
    *   Using the fundamental property: `a * x = b * c`
    *   Formula: `x = (b * c) / a`

2.  **Third Proportional:**
    *   If `a : b :: b : x`, then `x` is called the third proportional to `a` and `b`. (Here, `a, b, x` are in continued proportion).
    *   Using the fundamental property: `a * x = b * b = b^2`
    *   Formula: `x = b^2 / a`

3.  **Mean Proportional:**
    *   If `a : x :: x : b`, then `x` is called the mean proportional between `a` and `b`. (Here, `a, x, b` are in continued proportion).
    *   Using the fundamental property: `a * b = x * x = x^2`
    *   Formula: `x = sqrt(a * b)`

## Properties of Proportion (Often useful shortcuts)

If `a : b :: c : d` (or `a/b = c/d`), then:

*   **Invertendo:** `b : a :: d : c` (or `b/a = d/c`)
*   **Alternendo:** `a : c :: b : d` (or `a/c = b/d`)
*   **Componendo:** `(a+b) : b :: (c+d) : d` (or `(a+b)/b = (c+d)/d`)
*   **Dividendo:** `(a-b) : b :: (c-d) : d` (or `(a-b)/b = (c-d)/d`)
*   **Componendo and Dividendo:** `(a+b) : (a-b) :: (c+d) : (c-d)` (or `(a+b)/(a-b) = (c+d)/(c-d)`)
