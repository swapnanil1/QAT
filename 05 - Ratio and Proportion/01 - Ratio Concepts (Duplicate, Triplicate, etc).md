# Ratio Concepts (Duplicate, Triplicate, etc)

#quant #ratio_and_proportion #ratio_concepts #formula

## Definition

A ratio is a comparison of two quantities of the same kind by division. If `a` and `b` are two quantities of the same kind (in the same units), then the fraction `a/b` is called the ratio of `a` to `b`. It is written as `a : b`.

*   **Antecedent:** The first term (`a`) in the ratio `a : b`.
*   **Consequent:** The second term (`b`) in the ratio `a : b`.

**Key Properties:**
*   A ratio is a pure number, meaning it has no units.
*   The quantities being compared must be in the same units.
*   Multiplying or dividing both terms of a ratio by the same non-zero number does not change the ratio. E.g., 2 : 3 is the same as 4 : 6 or 1 : 1.5.
*   Ratios are usually expressed in their simplest form.

## Types of Ratios

1.  **Duplicate Ratio:** The ratio of the squares of the antecedent and consequent.
    *   If the ratio is `a : b`, the duplicate ratio is `a^2 : b^2`.
2.  **Triplicate Ratio:** The ratio of the cubes of the antecedent and consequent.
    *   If the ratio is `a : b`, the triplicate ratio is `a^3 : b^3`.
3.  **Sub-duplicate Ratio:** The ratio of the square roots of the antecedent and consequent.
    *   If the ratio is `a : b`, the sub-duplicate ratio is `sqrt(a) : sqrt(b)` or `a^(1/2) : b^(1/2)`.
4.  **Sub-triplicate Ratio:** The ratio of the cube roots of the antecedent and consequent.
    *   If the ratio is `a : b`, the sub-triplicate ratio is `cbrt(a) : cbrt(b)` or `a^(1/3) : b^(1/3)`.
5.  **Inverse Ratio (Reciprocal Ratio):** The ratio obtained by interchanging the antecedent and consequent.
    *   If the ratio is `a : b`, the inverse ratio is `b : a`.
6.  **Compound Ratio:** The ratio obtained by multiplying together the antecedents for a new antecedent and the consequent for a new consequent.
    *   If the ratios are `a : b`, `c : d`, and `e : f`, the compound ratio is `(a*c*e) : (b*d*f)`.

## Comparison of Ratios

To compare two ratios, `a : b` and `c : d`:
1.  Convert them to fractions: `a/b` and `c/d`.
2.  Find a common denominator (e.g., `b*d`).
3.  Compare the numerators: `(a*d)` and `(c*b)`.
    *   If `(a*d) > (c*b)`, then `a : b > c : d`.
    *   If `(a*d) < (c*b)`, then `a : b < c : d`.
    *   If `(a*d) = (c*b)`, then `a : b = c : d`.
Alternatively, convert the fractions to decimals and compare.
