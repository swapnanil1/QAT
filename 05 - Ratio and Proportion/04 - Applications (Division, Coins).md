# Applications of Ratio and Proportion (Division, Coins)

#quant #ratio_and_proportion #ratio_application #division #coin_problems #mcq_strategy

Ratios and proportions have direct applications in various quantitative aptitude problems, particularly in dividing quantities and solving problems involving mixtures (like coins of different denominations).

## 1. Division of a Quantity in a Given Ratio

This involves dividing a given total amount or quantity into several parts according to a specified ratio.

**Method:**

1.  **Ensure Ratio is Combined:** If the parts are related through multiple ratios (e.g., A:B and B:C), first find the combined ratio (e.g., A:B:C). See [[05 - Ratio and Proportion/03 - Combining Ratios (A B, B C - A B C).md]]. Let the final ratio be `a : b : c : ...`.
2.  **Sum the Ratio Parts:** Calculate the sum of the terms in the ratio: `Sum = a + b + c + ...`. This represents the total number of 'parts' the quantity is divided into.
3.  **Calculate Value per Part:** Divide the total quantity (Amount, Number, etc.) by the sum of the ratio parts: `Value per Part = Total Quantity / Sum`.
4.  **Calculate Individual Shares:** Multiply the value per part by the corresponding ratio term for each share:
    *   Share A = `a * Value per Part`
    *   Share B = `b * Value per Part`
    *   Share C = `c * Value per Part`
    *   ...and so on.

**Example:** Divide ₹1200 among A, B, and C in the ratio 2 : 3 : 5.
1.  Ratio = 2 : 3 : 5
2.  Sum of parts = 2 + 3 + 5 = 10 parts.
3.  Value per part = 1200 / 10 = ₹ 120.
4.  A's share = 2 * 120 = ₹ 240. B's share = 3 * 120 = ₹ 360. C's share = 5 * 120 = ₹ 600. (Check: 240+360+600 = 1200).

## 2. Problems Involving Coins

These problems typically involve a bag containing coins of different denominations (e.g., ₹1, 50 paise, 25 paise). Information might be given about the total value, the total number of coins, or the ratio between the number/value of different denominations.

**Common Scenarios:**

*   **Scenario A: Ratio of the *number* of coins is given.**
    1.  Let the ratio of the number of coins of Denomination 1, Denomination 2, Denomination 3 be `a : b : c`.
    2.  Assume the actual number of coins are `ax`, `bx`, and `cx` respectively, where `x` is a common multiplier.
    3.  Convert all denominations to a single unit (e.g., Rupees or Paise). Let the values be `v1, v2, v3`.
    4.  Calculate the total value in terms of `x`: `Total Value = (ax * v1) + (bx * v2) + (cx * v3)`.
    5.  Equate this expression to the given Total Value and solve for `x`.
    6.  Calculate the number of coins for each denomination (`ax`, `bx`, `cx`).

*   **Scenario B: Ratio of the *value* of coins is given.**
    1.  Let the ratio of the total value contributed by coins of Denomination 1, Denomination 2, Denomination 3 be `a : b : c`.
    2.  Assume the actual values contributed are `ax`, `bx`, and `cx` respectively.
    3.  The sum of these values is the total value: `Total Value = ax + bx + cx = (a+b+c)x`.
    4.  Equate this to the given Total Value and solve for `x`.
    5.  Find the value contributed by each denomination (`ax`, `bx`, `cx`).
    6.  If needed, find the number of coins for each denomination by dividing the value by the denomination: `Number_1 = ax / v1`, `Number_2 = bx / v2`, `Number_3 = cx / v3`.

**Key Considerations for Coin Problems:**

*   **Unit Consistency:** Convert all monetary values (denominations and total value) to the *same unit* (usually the smallest unit available, like Paise, to avoid decimals, or Rupees if preferred). 1 Rupee = 100 Paise.
*   **Ratio Type:** Carefully read whether the given ratio applies to the *number* of coins or the *value* of coins. This determines the correct approach.
