## Problem:

The triplicate ratio of two quantities A and B is 1728 : 27. The sub-duplicate ratio of quantities B and C is 2 : 5. Find the ratio A : C.

(A) 4 : 5
(B) 16 : 5
(C) 8 : 5
(D) 5 : 8

## Solution:

**1. Find the original ratio A : B from the triplicate ratio:**
   Given: Triplicate ratio `A^3 : B^3 = 1728 : 27`.
   To find the original ratio `A : B`, we take the cube root of both terms:
   `A : B = cbrt(1728) : cbrt(27)`
   We know `12^3 = 1728` and `3^3 = 27`.
   So, `A : B = 12 : 3`.
   Simplify the ratio by dividing both terms by their GCD (3):
   `A : B = 4 : 1`.

**2. Find the original ratio B : C from the sub-duplicate ratio:**
   Given: Sub-duplicate ratio `sqrt(B) : sqrt(C) = 2 : 5`.
   To find the original ratio `B : C`, we square both terms (find the duplicate ratio of the given sub-duplicate ratio):
   `B : C = (2)^2 : (5)^2`
   `B : C = 4 : 25`.

**3. Combine the ratios A : B and B : C to find A : C:**
   We have `A : B = 4 : 1`.
   We have `B : C = 4 : 25`.

   To combine these ratios and find `A : B : C`, the value corresponding to 'B' must be the same in both ratios.
   Multiply the first ratio (`A : B = 4 : 1`) by 4 to make the 'B' term equal to 4:
   `A : B = (4 * 4) : (1 * 4) = 16 : 4`.

   Now we have:
   `A : B = 16 : 4`
   `B : C =  4 : 25`

   The combined ratio `A : B : C` is `16 : 4 : 25`.

**4. Determine the required ratio A : C:**
   From the combined ratio `A : B : C = 16 : 4 : 25`, we can extract the ratio `A : C`.
   `A : C = 16 : 25`.

## Shortcut/Tip

*   **Know your powers/roots:** Quickly recalling common cubes (like 12³ = 1728, 3³ = 27) and squares/roots saves significant time.
*   **Understand the terms:** Be very clear about the difference between duplicate (`a^2:b^2`), triplicate (`a^3:b^3`), sub-duplicate (`sqrt(a):sqrt(b)`), and sub-triplicate (`cbrt(a):cbrt(b)`). A mix-up here is a common error.
*   **Ratio Combination:** Remember the technique for combining ratios `A:B` and `B:C`. Find the LCM of the terms corresponding to B, adjust the ratios accordingly, and then write the combined `A:B:C`.
*   **Simplify Early:** Simplify individual ratios (`12:3` to `4:1`) before combining them. This keeps the numbers smaller and calculations easier.
*   **Check Calculation:** If the answer doesn't match options, re-read the question carefully (did you use triplicate instead of duplicate?) and double-check arithmetic, especially roots and combining steps.
