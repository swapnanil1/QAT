# Basic Terminology in Profit and Loss

Tags: #quant #profit_and_loss #basic_terminology #concepts #cp #sp #profit #loss

## Introduction

Profit and Loss is a fundamental concept in quantitative aptitude, dealing with the monetary gain or loss incurred in a transaction, primarily buying and selling goods or services. Understanding the basic terminology is crucial for solving problems in this area.

## Core Terms

### 1. Cost Price (CP)

*   **Definition:** The price at which an article is purchased or manufactured. This is the amount spent by the seller to acquire or produce the item.
*   **Includes:** Purchase price, manufacturing costs, transportation costs, labor costs, overhead expenses (rent, electricity, repairs, etc.) associated with acquiring or preparing the item for sale.
*   **Effective Cost Price:** Often, overhead expenses are added to the basic purchase/manufacturing price to get the total (or effective) Cost Price, which is then used for profit/loss calculations.
    *   `Effective CP = Purchase Price + Overhead Expenses`

### 2. Selling Price (SP)

*   **Definition:** The price at which an article is sold. This is the amount the seller receives from the buyer.

### 3. Profit (or Gain)

*   **Definition:** Occurs when the Selling Price (SP) is greater than the Cost Price (CP). It represents the monetary gain made by the seller.
*   **Condition:** `SP > CP`
*   **Formula:**
    ```
    Profit = Selling Price - Cost Price
    Profit = SP - CP
    ```

### 4. Loss

*   **Definition:** Occurs when the Selling Price (SP) is less than the Cost Price (CP). It represents the monetary loss incurred by the seller.
*   **Condition:** `SP < CP`
*   **Formula:**
    ```
    Loss = Cost Price - Selling Price
    Loss = CP - SP
    ```
    *(Note: Loss is calculated as a positive value representing the amount lost).*

## Calculating Profit Percentage and Loss Percentage

These percentages express the profit or loss relative to the Cost Price. **Crucially, Profit% and Loss% are always calculated based on the Cost Price (CP), unless specifically stated otherwise.**

### 1. Profit Percentage (Profit %)

*   **Definition:** The profit expressed as a percentage of the cost price.
*   **Formula:**
    ```
    Profit % = (Profit / Cost Price) * 100 %
    Profit % = [(SP - CP) / CP] * 100 %
    ```

### 2. Loss Percentage (Loss %)

*   **Definition:** The loss expressed as a percentage of the cost price.
*   **Formula:**
    ```
    Loss % = (Loss / Cost Price) * 100 %
    Loss % = [(CP - SP) / CP] * 100 %
    ```

## Key Relationships

*   If there is a profit: `SP = CP + Profit = CP * (1 + Profit%/100)`
*   If there is a loss: `SP = CP - Loss = CP * (1 - Loss%/100)`
