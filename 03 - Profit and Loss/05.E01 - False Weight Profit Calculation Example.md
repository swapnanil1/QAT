# Example: False Weight and Claimed Profit Calculation

Tags: #quant #profit_and_loss #dishonest_dealer #false_weights #profit_calculation #profit_percentage #markup #example #tricky_question

Parent Concept: [[03 - Profit and Loss/05 - Dishonest Dealer (False Weights)]]

## Problem

A dishonest grocer claims to sell his goods at a profit of 10%. However, he uses a weighing stone that actually weighs 800 grams instead of 1 kilogram (1000 grams). Find his actual overall gain percentage.

## Analysis

This dealer is dishonest in two ways:
1.  **Quantity:** He uses an 800g weight but charges for 1000g.
2.  **Price:** He claims a 10% profit on the cost price (implying the cost of 1000g).

To find the actual gain percentage, we need to determine the actual cost incurred by the dealer (for the 800g he gives) and compare it to the actual revenue he receives (the price he charges for the supposed 1000g, calculated with his claimed 10% profit).

## Solution Method 1: Assuming Cost per Gram

1.  **Assume Base Cost:** Let the Cost Price (CP) of 1 gram of goods be ₹1.
    Therefore, the CP of 1000g (1kg) = ₹1000.
    And the CP of 800g = ₹800.

2.  **Calculate Dealer's Actual Cost:** The dealer provides only 800g to the customer.
    *   Dealer's Actual CP = Cost of 800g = **₹800**.

3.  **Calculate Dealer's Selling Price:** The dealer charges the customer for 1000g, and claims a 10% profit on the cost *of 1000g*.
    *   Claimed SP for 1000g = (CP of 1000g) * (1 + Claimed Profit % / 100)
    *   Claimed SP for 1000g = ₹1000 * (1 + 10 / 100)
    *   Claimed SP for 1000g = ₹1000 * 1.10 = ₹1100.
    *   This is the actual amount the customer pays. So, Dealer's Actual SP = **₹1100**.

4.  **Calculate Actual Profit:**
    *   Actual Profit = Dealer's Actual SP - Dealer's Actual CP
    *   Actual Profit = ₹1100 - ₹800 = ₹300.

5.  **Calculate Actual Profit Percentage:** (Based on Dealer's Actual CP)
    *   Actual Profit % = (Actual Profit / Dealer's Actual CP) * 100 %
    *   Actual Profit % = (300 / 800) * 100 %
    *   Simplify fraction: 300 / 800 = 3 / 8
    *   Actual Profit % = (3 / 8) * 100 % = 3 * 12.5 % = 37.5 %

## Solution Method 2: Using Ratio / Factors

1.  **Effect of False Weight:** Using 800g instead of 1000g.
    *   Gain Factor due to weight = True Weight / False Weight = 1000 / 800 = 10/8 = 5/4 = 1.25.
    *   This means for every unit cost, he gets 1.25 units of revenue just due to the weight difference if selling at claimed CP.

2.  **Effect of Claimed Profit:** Dealer marks up the price by 10%.
    *   Price Factor = 1 + Claimed Profit % / 100 = 1 + 10/100 = 1.10.

3.  **Combine the Effects (Successive Change):** The overall effect is the product of the factors.
    *   Overall Factor (SP / Actual CP) = Gain Factor from Weight * Price Factor
    *   Overall Factor = 1.25 * 1.10
    *   Overall Factor = (5/4) * (11/10) = 55 / 40 = 11 / 8 = 1.375

4.  **Calculate Actual Profit % from Overall Factor:**
    *   The Overall Factor represents (1 + Actual Profit % / 100).
    *   `1 + Actual Profit % / 100 = 1.375`
    *   `Actual Profit % / 100 = 1.375 - 1 = 0.375`
    *   `Actual Profit % = 0.375 * 100 = 37.5 %`

## Shortcut/Tip

*   Identify the two sources of dishonesty: quantity manipulation and price manipulation (claimed profit).
*   Calculate the effective SP (what the customer pays based on claimed weight and claimed profit) and the effective CP (cost of what the dealer actually gives).
*   The factor method `(Overall Factor = Weight Factor * Price Factor)` can be quicker if you're comfortable with it.

**Answer:** The grocer's actual overall gain percentage is 37.5%.
