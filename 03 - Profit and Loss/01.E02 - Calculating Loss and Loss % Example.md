# Example: Calculating Loss and Loss Percentage

Tags: #quant #profit_and_loss #basic_terminology #loss #loss_percentage #cost_price #selling_price #example

Parent Concept: [[03 - Profit and Loss/01 - Basic Terminology (CP, SP, Profit, Loss)]]

## Problem

Anita purchased 50 kilograms of wheat at ₹22 per kg. She sold the entire quantity at ₹1050. Calculate the total loss and the loss percentage incurred by Anita.

## Analysis

First, we need to calculate the total Cost Price (CP) for the entire quantity of wheat. Then, we compare the total CP with the given Selling Price (SP) to determine if there's a profit or loss. Since the problem asks for loss and loss percentage, we expect the SP to be less than the CP. Finally, we calculate the loss amount and the loss percentage based on the total CP.

## Solution

1.  **Calculate the Total Cost Price (CP):**
    *   Quantity of wheat = 50 kg
    *   Price per kg = ₹22
    *   Total CP = Quantity * Price per kg
    *   Total CP = 50 kg * ₹22/kg = ₹1100

2.  **Identify the Total Selling Price (SP):**
    *   The entire quantity was sold for ₹1050.
    *   Total SP = ₹1050

3.  **Check for Profit or Loss:**
    *   Compare Total SP and Total CP: Total SP (₹1050) < Total CP (₹1100).
    *   Therefore, there is a loss.

4.  **Calculate the Loss Amount:**
    *   Loss = Total CP - Total SP
    *   Loss = ₹1100 - ₹1050 = ₹50

5.  **Calculate the Loss Percentage:**
    *   Loss % is calculated based on the Total CP.
    *   Loss % = (Loss / Total CP) * 100 %
    *   Loss % = (₹50 / ₹1100) * 100 %
    *   Simplify the fraction: 50 / 1100 = 5 / 110 = 1 / 22
    *   Loss % = (1 / 22) * 100 %
    *   Loss % = 100 / 22 %
    *   Loss % = 50 / 11 %
    *   Loss % ≈ 4.5454... % or 4 6/11 %

## Shortcut/Tip

*   Ensure you calculate the *total* CP and *total* SP before determining profit or loss, especially when dealing with multiple units.
*   Remember Loss % = (Loss / CP) * 100. Simplify the fraction before converting to a percentage if possible. Sometimes the answer might be left as a fraction (like 50/11 %).

**Answer:** Anita incurred a total loss of ₹50, which is a loss percentage of 50/11 % (or approximately 4.55%).
