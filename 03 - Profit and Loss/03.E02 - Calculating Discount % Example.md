# Example: Calculating Discount Percentage

Tags: #quant #profit_and_loss #markup #discount #discount_percentage #marked_price #selling_price #cost_price #example #tricky_question

Parent Concept: [[03 - Profit and Loss/03 - Markup and Discount]]

## Problem

A trader marks his goods 30% above the Cost Price (CP). He then sells them making an overall profit of 10%. What is the discount percentage he offered on the Marked Price (MP)?

## Analysis

This problem requires finding the Discount Percentage. We are given the Cost Price (implicitly, as percentages are relative), the Markup Percentage, and the overall Profit Percentage.
Steps:
1.  Assume a Cost Price (e.g., CP = 100) for easier calculation.
2.  Calculate the Marked Price (MP) based on the CP and Markup %.
3.  Calculate the Selling Price (SP) based on the CP and the overall Profit %.
4.  Calculate the Discount Amount given (MP - SP).
5.  Calculate the Discount Percentage based on the Discount Amount and the MP (Discount % = (Discount Amount / MP) * 100).

## Solution

1.  **Assume a Cost Price (CP):**
    *   Let CP = ₹100. (Choosing 100 makes percentage calculations straightforward).

2.  **Calculate the Marked Price (MP):**
    *   Markup = 30% above CP.
    *   MP = CP * (1 + Markup % / 100)
    *   MP = 100 * (1 + 30 / 100)
    *   MP = 100 * (1.30) = ₹130

3.  **Calculate the Selling Price (SP):**
    *   Overall Profit = 10% on CP.
    *   SP = CP * (1 + Profit % / 100)
    *   SP = 100 * (1 + 10 / 100)
    *   SP = 100 * (1.10) = ₹110

4.  **Calculate the Discount Amount:**
    *   Discount Amount = Marked Price (MP) - Selling Price (SP)
    *   Discount Amount = ₹130 - ₹110 = ₹20

5.  **Calculate the Discount Percentage:**
    *   Discount is always calculated on the Marked Price (MP).
    *   Discount % = (Discount Amount / MP) * 100 %
    *   Discount % = (20 / 130) * 100 %
    *   Simplify the fraction: 20 / 130 = 2 / 13
    *   Discount % = (2 / 13) * 100 %
    *   Discount % = 200 / 13 %
    *   Discount % ≈ 15.38 %

## Alternative using Formulas Directly

Let M% be Markup %, D% be Discount %, P% be Profit %.
We know `SP = MP * (1 - D%/100)` and `MP = CP * (1 + M%/100)` and `SP = CP * (1 + P%/100)`.

Substitute MP in the first equation:
`SP = [CP * (1 + M%/100)] * (1 - D%/100)`

Equate the two expressions for SP:
`CP * (1 + P%/100) = [CP * (1 + M%/100)] * (1 - D%/100)`

Cancel CP from both sides:
`(1 + P%/100) = (1 + M%/100) * (1 - D%/100)`

Substitute known values (P=10, M=30):
`(1 + 10/100) = (1 + 30/100) * (1 - D%/100)`
`1.10 = 1.30 * (1 - D%/100)`

Solve for `(1 - D%/100)`:
`(1 - D%/100) = 1.10 / 1.30 = 11 / 13`

Solve for D%:
`D%/100 = 1 - (11 / 13)`
`D%/100 = (13 - 11) / 13 = 2 / 13`
`D% = (2 / 13) * 100 = 200 / 13 %`

## Shortcut/Tip

*   Assuming CP = 100 simplifies calculations involving percentages.
*   Remember the base for each percentage: Markup% is on CP, Discount% is on MP, Profit/Loss% is on CP.
*   The relationship `(1 + Profit%/100) = (1 + Markup%/100) * (1 - Discount%/100)` is useful for directly relating the three key percentages.

**Answer:** The discount percentage offered was 200/13 % or approximately 15.38%.
