# Example: Calculating Net Equivalent Single Discount

Parent Concept: [[03 - Profit and Loss/04 - Successive Discounts]]

## Problem 1

Find the single discount percentage that is equivalent to two successive discounts of 20% and 10%.

## Analysis (Problem 1)

We need to find a single percentage `D_net` such that applying `D_net%` discount to the Marked Price (MP) results in the same final Selling Price (SP) as applying a 20% discount followed by a 10% discount.

## Solution (Problem 1)

### Method 1: Assume MP = 100

1.  **Assume MP:** Let MP = 100.
2.  **Apply 1st Discount (20%):** Price = 100 * (1 - 20/100) = 100 * 0.80 = 80.
3.  **Apply 2nd Discount (10% on reduced price):** Price = 80 * (1 - 10/100) = 80 * 0.90 = 72.
4.  **Final SP:** SP = 72.
5.  **Total Discount Amount:** Total Discount = MP - SP = 100 - 72 = 28.
6.  **Net Discount %:** Net Discount % = (Total Discount / MP) * 100 % = (28 / 100) * 100 % = 28%.

### Method 2: Using Net Discount Formula (for Two Discounts)

1.  **Identify Discounts:** D1 = 20%, D2 = 10%.
2.  **Apply Formula:** `Net Discount % = [ D1 + D2 - (D1 * D2 / 100) ] %`
3.  **Calculate:**
    `Net Discount % = [ 20 + 10 - (20 * 10 / 100) ] %`
    `Net Discount % = [ 30 - (200 / 100) ] %`
    `Net Discount % = [ 30 - 2 ] % = 28 %`

### Method 3: Using Net Multiplication Factor

1.  **Calculate Individual Factors:**
    *   Factor 1 (20% off) = 0.80
    *   Factor 2 (10% off) = 0.90
2.  **Calculate Net Factor:** Net Factor = Factor 1 * Factor 2 = 0.80 * 0.90 = 0.72.
3.  **Calculate Net Discount %:** `Net Discount % = (1 - Net Factor) * 100 %`
    `Net Discount % = (1 - 0.72) * 100 % = 0.28 * 100 % = 28 %`

## Problem 2 (Tricky Variation)

A single discount equivalent to two successive discounts of 15% and x% is 23.5%. Find the value of x.

## Analysis (Problem 2)

Here, we know one of the successive discounts (D1 = 15%) and the net equivalent discount (D_net = 23.5%). We need to find the second successive discount (D2 = x%). We can use the Net Discount Formula and solve for the unknown.

## Solution (Problem 2)

1.  **Identify Knowns:** D1 = 15%, D_net = 23.5%, D2 = x%.
2.  **Apply Net Discount Formula:** `D_net = D1 + D2 - (D1 * D2 / 100)`
3.  **Substitute values:** `23.5 = 15 + x - (15 * x / 100)`
4.  **Simplify and Solve for x:**
    `23.5 = 15 + x - (15x / 100)`
    Subtract 15 from both sides:
    `23.5 - 15 = x - 15x / 100`
    `8.5 = x - 0.15x`
    `8.5 = (1 - 0.15)x`
    `8.5 = 0.85x`
    `x = 8.5 / 0.85`
    `x = 850 / 85`
    `x = 10`

## Shortcut/Tip

*   The formula `Net Discount % = D1 + D2 - (D1*D2/100)` is very efficient for finding the net discount or for finding one discount if the other and the net discount are known (as in Problem 2).
*   The multiplication factor method (`Net Factor = F1 * F2`, `Net Discount % = (1 - Net Factor) * 100`) is versatile for any number of discounts.

**Answer:**
Problem 1: The single equivalent discount is 28%.
Problem 2: The value of x (the second discount) is 10%.
