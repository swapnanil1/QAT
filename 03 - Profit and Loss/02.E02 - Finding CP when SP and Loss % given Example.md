# Example: Finding CP when SP and Loss % given (Multi-step)

Tags: #quant #profit_and_loss #cost_price #selling_price #loss_percentage #profit_percentage #example #tricky_question #multi_step

Parent Concept: [[03 - Profit and Loss/02 - Finding SP CP given Profit Loss %]]

## Problem

By selling an article for ₹810, a shopkeeper incurs a loss of 10%.
(a) Find the Cost Price (CP) of the article.
(b) At what price should the shopkeeper sell the article to gain a profit of 20%?

## Analysis

This problem has two parts:
1.  First, we need to find the Cost Price (CP) using the given Selling Price (SP) and the Loss Percentage. This directly uses the concept of this note.
2.  Second, using the CP calculated in the first part, we need to find the new Selling Price required to achieve a different outcome (a 20% profit).

## Solution

**Part (a): Find the Cost Price (CP)**

1.  **Identify the given values:**
    *   Selling Price (SP) = ₹810
    *   Loss Percentage (L%) = 10%

2.  **Apply the formula for CP when SP and Loss% are given:**
    *   `CP = SP * [100 / (100 - Loss %)]`
    *   `CP = 810 * [100 / (100 - 10)]`
    *   `CP = 810 * [100 / 90]`

3.  **Calculate the CP:**
    *   Simplify the fraction: `100 / 90 = 10 / 9`
    *   `CP = 810 * (10 / 9)`
    *   `CP = (810 / 9) * 10`
    *   `CP = 90 * 10`
    *   `CP = ₹900`

    *Alternatively using Multiplication Factor:*
    *   Loss of 10% means SP is (100 - 10)% = 90% of CP.
    *   Factor = `1 - L/100 = 1 - 10/100 = 0.9`
    *   `CP = SP / Factor`
    *   `CP = 810 / 0.9`
    *   `CP = 8100 / 9 = 900`

**Part (b): Find the new SP for a 20% Profit**

1.  **Identify the knowns for this part:**
    *   Cost Price (CP) = ₹900 (from Part a)
    *   Desired Profit Percentage (P%) = 20%

2.  **Apply the formula for SP when CP and Profit% are given:**
    *   `New SP = CP * [(100 + Profit %) / 100]`
    *   `New SP = 900 * [(100 + 20) / 100]`
    *   `New SP = 900 * [120 / 100]`

3.  **Calculate the New SP:**
    *   Simplify the fraction: `120 / 100 = 12 / 10 = 1.2`
    *   `New SP = 900 * 1.2`
    *   `New SP = 900 * (1 + 0.2) = 900 + (900 * 0.2)`
    *   `New SP = 900 + 180`
    *   `New SP = ₹1080`

    *Alternatively using Multiplication Factor:*
    *   Profit of 20% means New SP is (100 + 20)% = 120% of CP.
    *   Factor = `1 + P/100 = 1 + 20/100 = 1.2`
    *   `New SP = CP * Factor`
    *   `New SP = 900 * 1.2 = 1080`

## Shortcut/Tip

*   Finding CP when SP and Loss% are given involves dividing the SP by (1 - Loss%/100).
*   Finding SP when CP and Profit% are given involves multiplying the CP by (1 + Profit%/100).
*   Problems often link these calculations: finding the CP in one scenario and then using it to determine the required SP for a different profit/loss outcome.

**Answer:**
(a) The Cost Price (CP) of the article is ₹900.
(b) To gain a profit of 20%, the shopkeeper should sell the article for ₹1080.
