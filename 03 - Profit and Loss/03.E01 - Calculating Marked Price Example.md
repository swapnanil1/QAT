# Example: Calculating Marked Price

Tags: #quant #profit_and_loss #markup #discount #marked_price #cost_price #selling_price #profit_percentage #example #tricky_question

Parent Concept: [[03 - Profit and Loss/03 - Markup and Discount]]

## Problem

A shopkeeper wants to make a profit of 20% on an article whose Cost Price (CP) is ₹500. He decides to offer a discount of 10% to his customers. At what price should he mark the article (Marked Price, MP)?

## Analysis

This problem requires finding the Marked Price (MP). We know the Cost Price (CP) and the desired Profit Percentage. This allows us to calculate the target Selling Price (SP).
We also know the Discount Percentage that will be applied to the unknown MP to arrive at this target SP.
So, the steps are:
1.  Calculate the required Selling Price (SP) based on CP and desired Profit %.
2.  Use the relationship between SP, MP, and Discount % (`SP = MP * (1 - Discount % / 100)`) to find the MP.

## Solution

1.  **Calculate the Target Selling Price (SP):**
    *   Cost Price (CP) = ₹500
    *   Desired Profit % = 20%
    *   Target SP = CP * (1 + Profit % / 100)
    *   Target SP = 500 * (1 + 20 / 100)
    *   Target SP = 500 * (1 + 0.20)
    *   Target SP = 500 * 1.20 = ₹600

2.  **Find the Marked Price (MP):**
    *   The calculated SP (₹600) is the price after a 10% discount has been given on the MP.
    *   We know: `SP = MP * (1 - Discount % / 100)`
    *   Discount % = 10%
    *   Factor = `(1 - 10 / 100) = 1 - 0.10 = 0.90`
    *   So, `SP = MP * 0.90`
    *   Substitute the target SP: `600 = MP * 0.90`
    *   Rearrange to solve for MP: `MP = 600 / 0.90`
    *   `MP = 6000 / 9`
    *   `MP = 2000 / 3`
    *   `MP ≈ 666.67`

## Alternative Approach (Single Formula)

We can use the combined formula derived in the concept note:
`SP = CP * [(100 + Markup %) / 100] * [(100 - Discount %) / 100]` - *This isn't the right formula here as we don't know Markup %.*

Let's use the relationship linking SP, CP, MP, Discount%, and Profit%.
We know `SP = CP * (1 + Profit % / 100)` and `SP = MP * (1 - Discount % / 100)`.
Therefore:
`MP * (1 - Discount % / 100) = CP * (1 + Profit % / 100)`

Now substitute the known values:
`MP * (1 - 10 / 100) = 500 * (1 + 20 / 100)`
`MP * (1 - 0.10) = 500 * (1 + 0.20)`
`MP * 0.90 = 500 * 1.20`
`MP * 0.90 = 600`
`MP = 600 / 0.90 = 6000 / 9 = 2000 / 3 ≈ 666.67`

## Shortcut/Tip

*   Think step-by-step: Calculate the target SP first based on desired profit. Then, work backward from the SP using the discount percentage to find the MP (SP = MP * (1 - Discount % / 100) => MP = SP / (1 - Discount % / 100)).
*   The formula `MP * (1 - D%/100) = CP * (1 + P%/100)` directly links all the given and required values and can be faster if memorized.

**Answer:** The shopkeeper should mark the article at ₹2000/3 or approximately ₹666.67.
