# Average Speed (Equal Distances) Example

**Problem:**

A man travels from his home to his office at a speed of 30 km/hr and returns back home along the same route at a speed of 20 km/hr. What is his average speed for the entire journey (round trip)?

(A) 25 km/hr
(B) 24 km/hr
(C) 22 km/hr
(D) 26 km/hr

## Solution:

This problem involves two parts of a journey where the distance covered in each part is the same (home to office distance = office to home distance), but the speeds are different. This is a classic case for using the harmonic mean formula for average speed, as discussed in [[11 - Time, Speed and Distance/02 - Average Speed Concepts.md]].

Let the distance from home to office be `d` km.
Speed while going (s1) = 30 km/hr.
Speed while returning (s2) = 20 km/hr.

**Method 1: Using the Harmonic Mean Formula**

For two equal distances covered at speeds `s1` and `s2`, the average speed is given by:
`Average Speed = (2 * s1 * s2) / (s1 + s2)`

Substitute the given values:
Average Speed = `(2 * 30 * 20) / (30 + 20)`
Average Speed = `(2 * 600) / 50`
Average Speed = `1200 / 50`
Average Speed = `120 / 5`
Average Speed = 24 km/hr.

**Method 2: Using Basic Definitions (Total Distance / Total Time)**

1.  Let the distance one way be `d` km.
    Total Distance = Distance going + Distance returning = `d + d = 2d` km.

2.  Calculate time taken for each part:
    Time going (`t1`) = Distance / Speed1 = `d / 30` hours.
    Time returning (`t2`) = Distance / Speed2 = `d / 20` hours.

3.  Calculate Total Time:
    Total Time = `t1 + t2 = (d / 30) + (d / 20)`
    Find a common denominator (LCM of 30, 20 is 60):
    Total Time = `(2d / 60) + (3d / 60)`
    Total Time = `(2d + 3d) / 60 = 5d / 60 = d / 12` hours.

4.  Calculate Average Speed:
    Average Speed = Total Distance / Total Time
    Average Speed = `(2d) / (d / 12)`
    Average Speed = `2d * (12 / d)`
    Average Speed = `2 * 12` (The 'd' cancels out)
    Average Speed = 24 km/hr.

Both methods yield the same result: 24 km/hr. This matches option (B).

## Shortcut/Tip

1.  **Recognize Equal Distances:** Identify that the journey involves covering the *same distance* at different speeds (like a round trip on the same route).
2.  **Apply Harmonic Mean:** Immediately use the formula `Average Speed = (2 * s1 * s2) / (s1 + s2)` for two equal distance segments.
3.  **Avoid Simple Average:** The most common mistake is to calculate the simple average: `(30 + 20) / 2 = 25` km/hr (Option A). Remember, this is only correct if the *time* spent travelling at each speed is equal, which is not the case here (more time is spent at the slower speed). The average speed will always be closer to the lower speed when distances are equal.
