# Basic Calculation Example

**Problem:**

A person walks at a speed of 4 km/hr and covers a certain distance. If the person had walked at a speed of 9 km/hr, they would have covered 7.5 km more in the same amount of time. What is the actual distance covered by the person initially?

(A) 5 km
(B) 6 km
(C) 7.5 km
(D) 8 km

## Solution:

This problem involves two scenarios with different speeds but the same time duration. We can use the basic formula `Distance = Speed * Time` or `Time = Distance / Speed` from [[11 - Time, Speed and Distance/01 - Basic Formula (D=S T) and Unit Conversions.md]].

Let the actual distance covered initially be `D` km.
Let the time taken be `T` hours.

**Scenario 1 (Actual):**
Speed `S1 = 4` km/hr
Distance `D1 = D` km
Time `T = D1 / S1 = D / 4` hours.

**Scenario 2 (Hypothetical):**
Speed `S2 = 9` km/hr
Distance `D2 = D + 7.5` km (7.5 km more than the actual distance)
Time `T` is the *same* as in Scenario 1.
So, `T = D2 / S2 = (D + 7.5) / 9` hours.

**Equate the Time taken in both scenarios:**
Since the time `T` is the same in both cases:
`D / 4 = (D + 7.5) / 9`

**Solve for D:**
Cross-multiply:
`9 * D = 4 * (D + 7.5)`
`9D = 4D + (4 * 7.5)`
`9D = 4D + 30`

Subtract `4D` from both sides:
`9D - 4D = 30`
`5D = 30`

Divide by 5:
`D = 30 / 5`
`D = 6` km.

The actual distance covered initially by the person is 6 km. This matches option (B).

**Verification (Optional):**
If D = 6 km:
Time in Scenario 1 = D / S1 = 6 km / 4 km/hr = 1.5 hours.
Distance in Scenario 2 = D + 7.5 = 6 + 7.5 = 13.5 km.
Time in Scenario 2 = D2 / S2 = 13.5 km / 9 km/hr = 1.5 hours.
The time is indeed the same in both scenarios, confirming the answer.

## Shortcut/Tip

1.  **Focus on the Constant:** Identify the constant parameter, which is 'Time' in this case.
2.  **Set up Ratio:** Since `T = D/S` is constant, `D1/S1 = D2/S2`.
    `D / 4 = (D + 7.5) / 9`. This directly leads to the equation to solve.
3.  **Alternative Approach (Difference in Distance):**
    *   Let Time = `T`.
    *   Distance 1 = `S1 * T = 4T`.
    *   Distance 2 = `S2 * T = 9T`.
    *   The difference in distance is given: `D2 - D1 = 7.5` km.
    *   `9T - 4T = 7.5`
    *   `5T = 7.5`
    *   `T = 7.5 / 5 = 1.5` hours.
    *   The actual distance asked is `D1 = S1 * T = 4 * 1.5 = 6` km.
    This approach calculates the time first and then the required distance. It can be slightly faster if you are comfortable working with the time variable `T`.
