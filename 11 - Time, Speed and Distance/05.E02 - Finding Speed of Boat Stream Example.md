# Finding Speed of Boat Stream Example

**Problem:**
A boat covers a distance of 30 km downstream and returns covering the same distance upstream, taking a total of 8 hours for the entire journey. If the speed of the stream is 2 km/hr, what is the speed of the boat in still water?

(A) 6 km/hr
(B) 8 km/hr
(C) 10 km/hr
(D) 7.5 km/hr

## Solution:

This problem requires finding the speed of the boat in still water (`B`) given the total time for a round trip, the distance, and the speed of the stream (`S`). We will use the concepts from [[11 - Time, Speed and Distance/05 - Boats and Streams.md]].

**Step 1: Identify Given Information and Define Variables**
Distance one way (`Dist`) = 30 km.
Total Time (`T_total`) = 8 hours.
Speed of Stream (`S`) = 2 km/hr.
Let the Speed of Boat in Still Water be `B` km/hr.

**Step 2: Express Downstream and Upstream Speeds in terms of B**
Downstream Speed (`D`) = `B + S` = `B + 2` km/hr.
Upstream Speed (`U`) = `B - S` = `B - 2` km/hr.
*(Assumption: `B > S`, i.e., `B > 2` for the boat to travel upstream).*

**Step 3: Express Time Taken for Each Leg in terms of B**
Using the formula `Time = Distance / Speed` from [[11 - Time, Speed and Distance/01 - Basic Formula (D=S T) and Unit Conversions.md]]:
Time Downstream (`Td`) = `Dist / D` = `30 / (B + 2)` hours.
Time Upstream (`Tu`) = `Dist / U` = `30 / (B - 2)` hours.

**Step 4: Formulate Equation Based on Total Time**
Total Time = Time Downstream + Time Upstream
`T_total = Td + Tu`
8 = `30 / (B + 2) + 30 / (B - 2)`

**Step 5: Solve the Equation for B**
To solve, find a common denominator on the right side: `(B + 2)(B - 2) = B^2 - 4`.
8 = `[30 * (B - 2) + 30 * (B + 2)] / [(B + 2)(B - 2)]`
8 = `[30*B - 60 + 30*B + 60] / (B^2 - 4)`
8 = `(60*B) / (B^2 - 4)`

Multiply both sides by `(B^2 - 4)`:
`8 * (B^2 - 4) = 60*B`
`8*B^2 - 32 = 60*B`

Rearrange into a standard quadratic equation form (`a*x^2 + b*x + c = 0`):
`8*B^2 - 60*B - 32 = 0`

Divide the entire equation by 4 to simplify:
`2*B^2 - 15*B - 8 = 0`

**Step 6: Solve the Quadratic Equation**
We can solve this by factoring or using the quadratic formula. Let's try factoring. We need two numbers that multiply to `2 * (-8) = -16` and add up to `-15`. These numbers are -16 and +1.
Rewrite the middle term:
`2*B^2 - 16*B + 1*B - 8 = 0`
Factor by grouping:
`2*B * (B - 8) + 1 * (B - 8) = 0`
`(2*B + 1) * (B - 8) = 0`

This gives two possible solutions for `B`:
`2*B + 1 = 0` => `B = -1/2`
`B - 8 = 0` => `B = 8`

Since the speed of the boat (`B`) cannot be negative, we discard `B = -1/2`.
Therefore, the speed of the boat in still water (`B`) is 8 km/hr.

*(Self-check: If B=8, S=2, then D=10, U=6. Td = 30/10 = 3 hrs. Tu = 30/6 = 5 hrs. Total Time = 3 + 5 = 8 hrs. Matches problem statement.)*

## Shortcut/Tip
1.  **Setup:** The core step is setting up the equation `T_total = Dist/(B+S) + Dist/(B-S)`.
2.  **Quadratic:** Recognize that this setup often leads to a quadratic equation. Be prepared to solve it efficiently.
3.  **MCQ Strategy - Option Testing:** Since solving the quadratic equation can be time-consuming, testing the options can be faster in an exam setting.
    *   Take an option, e.g., `B = 8` km/hr (Option B).
    *   Calculate `D = 8 + 2 = 10` km/hr, `U = 8 - 2 = 6` km/hr.
    *   Calculate `Td = 30 / 10 = 3` hours.
    *   Calculate `Tu = 30 / 6 = 5` hours.
    *   Calculate Total Time = 3 + 5 = 8 hours.
    *   This matches the given total time, so Option B is correct.
    *   If the first option tested doesn't match, try another, preferably one that gives "cleaner" numbers for `B+S` and `B-S` as divisors of the distance.
