# Example: Divisibility by 8

**Tags:** #quant #number_system #divisibility #example #divisibility_by_8

**Concept:** [[01 - Divisibility Rules]]

---

**Problem:**
Is the number 9876512 divisible by 8?

**Rule Applied:**
A number is divisible by 8 if the number formed by its last three digits is divisible by 8.

**Solution:**
1.  Identify the last three digits of the number 9876**512**. The number formed is 512.
2.  Check if 512 is divisible by 8.
3.  Perform the division: 512 / 8.
    *   51 / 8 = 6 remainder 3.
    *   Bring down 2, making it 32.
    *   32 / 8 = 4.
    *   The division is exact (512 / 8 = 64).

**Conclusion:**
Since the number formed by the last three digits (512) is divisible by 8, the original number 9876512 **is** divisible by 8.

**Shortcut/Exam Tip:**
You only need to check the last three digits, ignoring the rest of the potentially very large number. This saves significant time. If the last 3 digits were, say, 610, you'd check 610/8, find it's not exact, and conclude the original number isn't divisible by 8.
