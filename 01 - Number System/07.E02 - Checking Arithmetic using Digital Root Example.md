# Checking Arithmetic using Digital Root Example

**Problem:**

Which of the following is the most likely result of the multiplication `345 * 678`? (Use the digital root method to check).

(A) 233910
(B) 233920
(C) 234010
(D) 234910

## Solution:

This problem asks us to find the correct product among the options, suggesting we can use the digital root property to quickly verify the arithmetic, as explained in [[01 - Number System/07 - Digital Root (Casting Out Nines).md]] (Describes how digital roots behave under arithmetic operations). The property states that `DR(A * B) = DR(DR(A) * DR(B))`.

**Step 1: Calculate the Digital Root (DR) of the first number (345).**
   DR(345) = 3 + 4 + 5 = 12
   DR(12) = 1 + 2 = 3.
   So, DR(345) = 3.
   (Using casting out nines: 4+5=9, ignore. Remaining is 3. DR=3).

**Step 2: Calculate the Digital Root (DR) of the second number (678).**
   DR(678) = 6 + 7 + 8 = 21
   DR(21) = 2 + 1 = 3.
   So, DR(678) = 3.

**Step 3: Calculate the expected Digital Root of the product.**
   Expected DR = DR( DR(345) * DR(678) )
   Expected DR = DR( 3 * 3 )
   Expected DR = DR( 9 )
   Expected DR = 9.
   The digital root of the correct product should be 9.

**Step 4: Calculate the Digital Root of each option.**
   - **(A) 233910:**
     DR = 2 + 3 + 3 + 9 + 1 + 0 = 18
     DR(18) = 1 + 8 = 9.
     (Casting out nines: Ignore 9. 2+3+3+1 = 9. DR=9). **Matches.**
   - **(B) 233920:**
     DR = 2 + 3 + 3 + 9 + 2 + 0 = 19
     DR(19) = 1 + 0 = 1. **Mismatch.**
   - **(C) 234010:**
     DR = 2 + 3 + 4 + 0 + 1 + 0 = 10
     DR(10) = 1 + 0 = 1. **Mismatch.**
   - **(D) 234910:**
     DR = 2 + 3 + 4 + 9 + 1 + 0 = 19
     DR(19) = 1 + 0 = 1. **Mismatch.**

**Step 5: Conclude the answer.**
   Only option (A) has a digital root (9) that matches the expected digital root calculated from the input numbers. Therefore, 233910 is the most likely correct answer.

This matches option (A).

## Shortcut/Tip

*   **Casting Out Nines:** Use the "casting out nines" shortcut to quickly find the digital root of large numbers. Ignore any 9s and any combination of digits that sum to 9 (or multiples of 9). Example for 233910: Ignore 9. 2+3+3+1 = 9. DR = 9.
*   **Verification, Not Proof:** Remember that matching digital roots provide a strong indication but *do not guarantee* correctness. Errors like transposition (e.g., writing 239310 instead of 233910) might result in the same digital root but a wrong answer. However, a *mismatch* in digital roots *guarantees* that the calculation is incorrect.
*   **Applicability:** This checking method works for addition, subtraction (handle borrowing carefully or use modulo 9 arithmetic), and multiplication. It does not directly apply to division in the same way.
*   **MCQ Strategy:** In timed tests, using digital roots can rapidly eliminate incorrect options for arithmetic problems, saving valuable time compared to performing the full calculation.
