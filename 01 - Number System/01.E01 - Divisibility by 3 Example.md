# Divisibility by 3 Example

**Problem:** What is the sum of all possible single-digit values of `x` such that the 7-digit number `42x1985` is divisible by 3?

(A) 7
(B) 10
(C) 12
(D) 15

## Solution:

This problem requires applying the divisibility rule for 3, as detailed in the parent concept [[01 - Number System/01 - Divisibility Rules.md]] (Provides the core rule used here: sum of digits must be divisible by 3).

Step 1: Calculate the sum of the known digits in the number `42x1985`.
Sum = 4 + 2 + 1 + 9 + 8 + 5 = 29.

Step 2: According to the divisibility rule for 3, the total sum of digits (`29 + x`) must be divisible by 3.

Step 3: Identify the multiples of 3 that are close to 29 and could be formed by adding a single digit `x` (where `x` can range from 0 to 9).
The possible sums are:
   - 30 (requires 29 + x = 30 => x = 1)
   - 33 (requires 29 + x = 33 => x = 4)
   - 36 (requires 29 + x = 36 => x = 7)
   - 39 (requires 29 + x = 39 => x = 10 - not a single digit)

Step 4: List all possible single-digit values for `x`.
The possible values for `x` are 1, 4, and 7.

Step 5: Calculate the sum of these possible values of `x`.
Sum = 1 + 4 + 7 = 12.

This matches option (C).

## Shortcut/Tip

*   **Quick Sum Check:** Instead of summing all digits first, you can often "cast out" digits that are already multiples of 3 (like 9) or pairs/groups that add up to multiples of 3 (like 4+2=6, 1+8=9). Here: 4+2 = 6 (ignore), 9 (ignore), 1+8 = 9 (ignore), 5 remains. So we need `5 + x` to be divisible by 3. Multiples of 3 near 5 are 6, 9, 12.
    *   If `5 + x = 6`, then `x = 1`.
    *   If `5 + x = 9`, then `x = 4`.
    *   If `5 + x = 12`, then `x = 7`.
    This gets the same possible values (1, 4, 7) much faster. Sum = 1+4+7 = 12.
*   **Remainder Approach:** Find the remainder when the sum of known digits is divided by 3. Sum = 29. Remainder(29 / 3) = 2. We need (Remainder + `x`) to be divisible by 3. So, `2 + x` must be divisible by 3. Possible values for `2 + x` are 3, 6, 9. This gives `x = 1, 4, 7`.
*   **Distractor Awareness:** Notice how options might correspond to individual possible values of `x` (like 7) or incorrect sums. Read the question carefully to ensure you're answering what is asked (the *sum* of possible values, not just one value). Option (D) 15 might arise if someone mistakenly includes `x=0` and `x=3` thinking the sum itself needs to contain those digits, or includes `x=10` incorrectly.
