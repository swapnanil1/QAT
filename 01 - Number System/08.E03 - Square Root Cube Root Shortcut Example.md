# Square Root Cube Root Shortcut Example

**Problem:**

What is the cube root of 50653? (³√50653 = ?)

(A) 27
(B) 37
(C) 43
(D) 33

## Solution:

This problem asks for the cube root of 50653. Assuming it's a perfect cube (common in aptitude tests unless approximation is asked), we can use shortcut methods based on unit digits and range estimation, as mentioned in [[01 - Number System/08 - Simplification and Approximation.md]] (Discusses shortcuts for roots).

**Step 1: Analyze the Unit Digit.**
   - The unit digit of the number 50653 is 3.
   - We need to find which digit, when cubed, results in a unit digit of 3. Let's check the cubes of digits 0-9:
     - 0³=0 -> Unit digit 0
     - 1³=1 -> Unit digit 1
     - 2³=8 -> Unit digit 8
     - 3³=27 -> Unit digit 7
     - 4³=64 -> Unit digit 4
     - 5³=125 -> Unit digit 5
     - 6³=216 -> Unit digit 6
     - 7³=343 -> Unit digit 3
     - 8³=512 -> Unit digit 2
     - 9³=729 -> Unit digit 9
   - The only digit whose cube ends in 3 is 7.
   - Therefore, the unit digit of the cube root of 50653 must be 7.

**Step 2: Range Estimation (Grouping Digits).**
   - Group the digits of the number from the right in sets of three: `50 | 653`.
   - Consider the first group (from the left), which is 50.
   - Find the largest integer whose cube is less than or equal to 50.
     - 1³ = 1
     - 2³ = 8
     - 3³ = 27
     - 4³ = 64 (This is greater than 50)
   - The largest cube less than or equal to 50 is 27, which is 3³.
   - This means the tens digit of the cube root is 3.

**Step 3: Combine the Digits.**
   - From Step 1, the unit digit of the cube root is 7.
   - From Step 2, the tens digit of the cube root is 3.
   - Combining these, the cube root is 37.

This matches option (B).

## Shortcut/Tip

*   **Cube Root Unit Digits:** Memorize or quickly deduce the unique mapping between the unit digit of a number and the unit digit of its cube: (0->0, 1->1, 2->8, 3->7, 4->4, 5->5, 6->6, 7->3, 8->2, 9->9). Note that each digit 0-9 appears exactly once as a unit digit of a cube.
*   **Grouping for Tens Digit:** Group digits in threes from the right (`XX | XXX`). Find the largest integer `N` such that `N³` is less than or equal to the leftmost group. This `N` gives the tens digit (or leading digits for very large numbers) of the cube root.
*   **Perfect Cubes Assumption:** This shortcut method generally assumes the given number is a perfect cube. It's highly effective in MCQ contexts where perfect cubes are commonly used for such questions.
*   **Square Roots:** A similar (but slightly more complex) method exists for square roots, involving unit digit analysis (note: 1/9 -> 1; 2/8 -> 4; 3/7 -> 9; 4/6 -> 6; 5->5; 0->0 - ambiguity exists) and range estimation (grouping in pairs from the right).
*   **Check Options:** If unsure, you can quickly cube the unit digits of the options. Here, (A) ends in 7³->3, (B) ends in 7³->3, (C) ends in 3³->7, (D) ends in 3³->7. This eliminates C and D immediately. Then estimate: 30³=27000, 40³=64000. Since 50653 is between 27000 and 64000, the root is between 30 and 40. Combining this with the unit digit 7 gives 37.
