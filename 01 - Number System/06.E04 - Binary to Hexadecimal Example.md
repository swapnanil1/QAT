# Example: Binary to Hexadecimal Conversion Shortcut

**Tags:** #quant #number_system #base_conversion #example #binary_to_hexadecimal #shortcut

**Concept:** [[06 - Base Conversions]]

---

**Problem:**
Convert the binary number 1101101₂ to its hexadecimal equivalent (base-16).

**Method Applied:**
Group binary digits into sets of 4 (starting from the right) and convert each group to its hex equivalent.

**Solution:**

1.  **Binary Number:** 1101101₂
2.  **Group into sets of 4 from the right:**
    *   Add leading zeros if the leftmost group is incomplete.
    *   `0110` `1101`
3.  **Convert each 4-bit group to Hex:**
    *   `0110₂`: (0*8 + 1*4 + 1*2 + 0*1) = 4 + 2 = 6₁₀ = **6₁₆**
    *   `1101₂`: (1*8 + 1*4 + 0*2 + 1*1) = 8 + 4 + 1 = 13₁₀ = **D₁₆** (Remember A=10, B=11, C=12, D=13...)
4.  **Concatenate the Hex digits:** 6 D

**Conclusion:**
The binary number 1101101₂ is equivalent to **6D₁₆** in hexadecimal.

**Shortcut/Exam Tip:**
This grouping method (3 bits for Octal, 4 bits for Hex) is much faster than converting Binary -> Decimal -> Hex/Octal. Memorizing or quickly deriving the 4-bit binary patterns for hex digits 0-F is essential for speed.
