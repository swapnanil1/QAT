# Example: Binary to Decimal Conversion

**Tags:** #quant #number_system #base_conversion #example #binary_to_decimal

**Concept:** [[06 - Base Conversions]]

---

**Problem:**
Convert the binary number 1101₂ to its decimal equivalent (base-10).

**Method Applied:**
Sum of (Digit * Base^PlaceValue). The base is 2. Place values (right-to-left) are 2⁰, 2¹, 2², 2³, ...

**Solution:**

1.  **Identify digits and place values:**
    *   Binary number: 1 1 0 1
    *   Place values: 2³ 2² 2¹ 2⁰
    *   (Values):    8  4  2  1

2.  **Multiply each digit by its place value:**
    *   (1 * 2³) = 1 * 8 = 8
    *   (1 * 2²) = 1 * 4 = 4
    *   (0 * 2¹) = 0 * 2 = 0
    *   (1 * 2⁰) = 1 * 1 = 1

3.  **Sum the products:**
    *   Sum = 8 + 4 + 0 + 1 = 13

**Conclusion:**
The binary number 1101₂ is equivalent to **13₁₀** in decimal.

**Shortcut/Exam Tip:**
This method works for converting *any* base back to decimal. Simply use the appropriate base (e.g., 8 for octal, 16 for hex) in the place value calculation. Knowing powers of 2 quickly (1, 2, 4, 8, 16, 32, 64...) helps speed up binary-to-decimal conversions.
