# Example: Unit Digit of Large Power (Cycle Length 2)

**Tags:** #quant #number_system #units_digit #example #cyclicity #powers

**Concept:** [[05 - Units Digit]]

---

**Problem:**
Find the units digit of (214)⁹⁸ + (529)⁵³.

**Method Applied:**
Find the units digit of each term separately using cyclicity rules and then add them (considering only the units digit of the sum).

**Solution:**

**Part 1: Units digit of (214)⁹⁸**
1.  **Base Units Digit:** 4.
2.  **Cycle for 4:** The cycle is (4, 6). Length `L = 2`.
3.  **Exponent Remainder:** Exponent is 98. Find `Rem(98 / 2)`.
    *   98 is an even number, so 98 / 2 = 49 with remainder 0. `Rem = 0`.
4.  **Find Units Digit:** Since `Rem = 0`, the units digit is the last (2nd) digit in the cycle (4, **6**), which is 6.
    *   Alternatively, for base 4: even exponent gives units digit 6.

**Part 2: Units digit of (529)⁵³**
1.  **Base Units Digit:** 9.
2.  **Cycle for 9:** The cycle is (9, 1). Length `L = 2`.
3.  **Exponent Remainder:** Exponent is 53. Find `Rem(53 / 2)`.
    *   53 is an odd number. 53 = 2 * 26 + 1. `Rem = 1`.
4.  **Find Units Digit:** Since `Rem = 1`, the units digit is the 1st digit in the cycle (**9**, 1), which is 9.
    *   Alternatively, for base 9: odd exponent gives units digit 9.

**Part 3: Combine the Results**
1.  We need the units digit of (Number ending in 6) + (Number ending in 9).
2.  Units digit = Units digit of (6 + 9) = Units digit of (15).

**Conclusion:**
The units digit of (214)⁹⁸ + (529)⁵³ is **5**.

**Shortcut/Exam Tip:**
For bases ending in 4 or 9, simply check if the exponent is odd or even:
*   4^(odd) ends in 4; 4^(even) ends in 6.
*   9^(odd) ends in 9; 9^(even) ends in 1.
Apply this, find the units digits (6 and 9), then find the units digit of their sum (6+9=15 -> 5).
