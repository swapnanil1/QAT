# Finding Number of Factors Example

**Problem:** How many distinct positive factors does the number 420 have?

(A) 12
(B) 20
(C) 24
(D) 9

## Solution:

This problem requires finding the total number of factors of 420. We use the method described in the parent concept [[01 - Number System/02 - Factors and Multiples.md]] (Explains how to find the number of factors using prime factorization).

Step 1: Find the prime factorization of 420.
   420 = 10 * 42
   420 = (2 * 5) * (6 * 7)
   420 = (2 * 5) * (2 * 3 * 7)
   Combining the prime factors:
   420 = 2 * 2 * 3 * 5 * 7
   420 = 2^2 * 3^1 * 5^1 * 7^1

Step 2: Identify the distinct prime factors and their powers.
   The prime factors are 2, 3, 5, and 7.
   Their respective powers are a=2, b=1, c=1, d=1.

Step 3: Apply the formula for the number of factors: `Number of Factors = (a + 1)(b + 1)(c + 1)(d + 1)`.
   Number of Factors = (2 + 1) * (1 + 1) * (1 + 1) * (1 + 1)
   Number of Factors = 3 * 2 * 2 * 2
   Number of Factors = 24

This matches option (C).

## Shortcut/Tip

*   **Systematic Factorization:** Start dividing the number by the smallest prime factor (2), then move to 3, 5, 7, etc., until the quotient becomes 1. This ensures you don't miss any prime factors.
    420 / 2 = 210
    210 / 2 = 105
    105 / 3 = 35
    35 / 5 = 7
    7 / 7 = 1
    Factors: 2, 2, 3, 5, 7 -> 2^2 * 3^1 * 5^1 * 7^1.
*   **The "+1" Rule:** The most common mistake is forgetting to add 1 to each exponent before multiplying. Remember, the power `p^a` contributes factors `p^0, p^1, ..., p^a`, which are `a+1` options in total.
*   **Distractor Check:**
    *   Option (A) 12: Might result from missing the factor 7 (2^2 * 3^1 * 5^1 -> (2+1)(1+1)(1+1) = 3*2*2 = 12) or missing one factor of 2 (2^1 * 3^1 * 5^1 * 7^1 -> (1+1)(1+1)(1+1)(1+1) = 16 - not an option, but similar error type).
    *   Option (D) 9: Could come from adding the `(power + 1)` terms instead of multiplying: (2+1) + (1+1) + (1+1) + (1+1) = 3 + 2 + 2 + 2 = 9.
    *   Option (B) 20: Could arise from incorrectly calculating the product (e.g., 5 * 4 from some mis-factorization). Ensure careful multiplication.
