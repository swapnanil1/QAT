# Remainder Cyclicity Example

**Problem:**

What is the remainder when 3^101 is divided by 7?

(A) 1
(B) 2
(C) 4
(D) 5

## Solution:

This problem asks for the remainder of a large power (3^101) when divided by 7. We can solve this efficiently using the concept of cyclicity of remainders, as discussed in [[01 - Number System/04 - Remainder Theorem.md]] (Mentions cyclicity as a method for handling large powers).

**Step 1: Calculate the remainders of the first few powers of 3 when divided by 7.**
   - Rem(3^1 / 7) = Rem(3 / 7) = 3
   - Rem(3^2 / 7) = Rem(9 / 7) = 2
   - Rem(3^3 / 7) = Rem(3^2 * 3 / 7) = Rem(2 * 3 / 7) = Rem(6 / 7) = 6
   - Rem(3^4 / 7) = Rem(3^3 * 3 / 7) = Rem(6 * 3 / 7) = Rem(18 / 7) = 4
   - Rem(3^5 / 7) = Rem(3^4 * 3 / 7) = Rem(4 * 3 / 7) = Rem(12 / 7) = 5
   - Rem(3^6 / 7) = Rem(3^5 * 3 / 7) = Rem(5 * 3 / 7) = Rem(15 / 7) = 1
   - Rem(3^7 / 7) = Rem(3^6 * 3 / 7) = Rem(1 * 3 / 7) = Rem(3 / 7) = 3

**Step 2: Identify the cycle and its length.**
The sequence of remainders is (3, 2, 6, 4, 5, 1, 3, ...). The pattern (3, 2, 6, 4, 5, 1) repeats.
The length of the cycle is 6.

**Step 3: Find the remainder of the exponent when divided by the cycle length.**
We need to find the remainder of the exponent 101 when divided by the cycle length 6.
101 divided by 6:
101 = 16 * 6 + 5.
The remainder is 5.

**Step 4: Determine the final remainder.**
The remainder of 3^101 divided by 7 will be the same as the remainder of 3 raised to the power of the exponent's remainder (which is 5). This corresponds to the 5th term in our cycle.
The 5th term in the cycle (3, 2, 6, 4, 5, 1) is 5.
Alternatively, calculate Rem(3^5 / 7) = 5 (from Step 1).

So, the remainder when 3^101 is divided by 7 is 5.

This matches option (D).

## Shortcut/Tip

*   **Stop at 1:** The cycle of remainders will always start repeating after a remainder of 1 is obtained (because the next term will be `Rem(1 * base / divisor)` which is the same as the first term). Once you reach Rem(3^6 / 7) = 1, you know the cycle length is 6.
*   **Exponent Remainder:** The key is to find the remainder of the *exponent* when divided by the *cycle length*. `Exponent_Rem = Exponent mod Cycle_Length`.
*   **Mapping:** The final answer is the term in the cycle sequence corresponding to the `Exponent_Rem`. If `Exponent_Rem` is 1, use the 1st term; if 2, use the 2nd term; ..., if 0 (or equal to cycle length), use the *last* term of the cycle (the one that gives remainder 1). Here, `Exponent_Rem` was 5, so we used the 5th term (5).
*   **Fermat's Little Theorem Connection:** Since 7 is prime and 3 is not divisible by 7, [[01 - Number System/04 - Remainder Theorem.md]] mentions Fermat's Little Theorem: `3^(7-1) ≡ 3^6 ≡ 1 (mod 7)`. This directly tells us the cycle length divides 6 (it is exactly 6 in this case) and confirms `Rem(3^6 / 7) = 1`, potentially speeding up finding the cycle. Then, `3^101 = 3^(6*16 + 5) = (3^6)^16 * 3^5 ≡ 1^16 * 3^5 ≡ 3^5 (mod 7)`. Calculating `3^5 mod 7 = 243 mod 7 = 5`.
*   **Distractor Check:** Option (A) 1 corresponds to an exponent remainder of 0 or 6. Option (B) 2 is the 2nd term in the cycle (exponent remainder 2). Option (C) 4 is the 4th term (exponent remainder 4). Make sure to use the correct exponent remainder (5 in this case).
