# Negative Remainder Example

**Problem:**

What is the remainder when (77 * 158 * 83) is divided by 20?

(A) 3
(B) 6
(C) 18
(D) 12

## Solution:

This problem involves finding the remainder of a product. We can use the properties of modular arithmetic, specifically the concept of negative remainders, to simplify calculations, as mentioned in [[01 - Number System/04 - Remainder Theorem.md]] (Discusses properties including negative remainders).

**Step 1: Find the remainder of each number in the product when divided by 20.**
   - Remainder of 77 divided by 20:
     77 = 3 * 20 + 17. The positive remainder is 17.
     The negative remainder is 17 - 20 = -3.
   - Remainder of 158 divided by 20:
     158 = 7 * 20 + 18. The positive remainder is 18.
     The negative remainder is 18 - 20 = -2.
   - Remainder of 83 divided by 20:
     83 = 4 * 20 + 3. The positive remainder is 3. (This is small, so we can use it directly).

**Step 2: Use the property `Rem((a * b * c) / n) = Rem( (Rem(a/n) * Rem(b/n) * Rem(c/n)) / n )`.**
We can use either positive or negative remainders. Using negative remainders often simplifies multiplication when the positive remainder is large (close to the divisor).

Calculation using negative remainders for 77 and 158:
Remainder = Rem ( (Rem(77/20) * Rem(158/20) * Rem(83/20)) / 20 )
Remainder = Rem ( (-3 * -2 * 3) / 20 )
Remainder = Rem ( (6 * 3) / 20 )
Remainder = Rem ( 18 / 20 )
Remainder = 18

**Step 3: Ensure the final remainder is positive and less than the divisor.**
The calculated remainder is 18, which is positive and less than 20.

This matches option (C).

*(Comparison with positive remainders: Rem( (17 * 18 * 3) / 20 ). Calculate 17 * 18 = 306. Rem(306 / 20) = 6. Then Rem( (6 * 3) / 20 ) = Rem( 18 / 20 ) = 18. This involves larger intermediate multiplications.)*

## Shortcut/Tip

*   **When to Use Negative Remainders:** Employ negative remainders when the standard positive remainder `r` is large (i.e., close to the divisor `b`). The negative remainder `r-b` will have a smaller absolute value, simplifying multiplications. In this example, using -3 instead of 17 and -2 instead of 18 significantly reduced the size of the numbers being multiplied.
*   **Mix and Match:** You can use a mix of positive and negative remainders in the same calculation, choosing whichever has the smaller absolute value for each term (e.g., we used -3, -2, and +3).
*   **Final Conversion:** If your final result after multiplication is negative (e.g., if the product was -18), convert it back to the standard positive remainder by adding the divisor. Rem(-18 / 20) is equivalent to Rem(-18 + 20 / 20) = Rem(2 / 20) = 2. (Our result was positive 18, so no conversion needed).
*   **Modular Arithmetic Property:** This example hinges on the property `(a * b) mod n = ((a mod n) * (b mod n)) mod n`.
