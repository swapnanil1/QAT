# Selecting a Committee Example

**Problem:**
A committee of 5 members is to be formed from a group of 7 men and 5 women. In how many ways can this be done if the committee must have exactly 3 men and 2 women?

(A) 350
(B) 45
(C) 792
(D) 2100

## Solution:

This problem involves selecting a subgroup (committee) from a larger group containing distinct categories (men and women), with specific constraints on the composition of the subgroup. Since the order in which the members are selected for the committee does not matter, this is a combination problem, using the `nCr` formula discussed in [[15 - Permutations and Combinations/03 - Combination (Selection) Formula (nCr).md|the combination concept note]].

**Step 1: Identify the Tasks and Constraints**
We need to form a committee of 5 members.
Available: 7 men, 5 women.
Constraint: The committee must consist of exactly 3 men AND exactly 2 women.

**Step 2: Break Down the Selection Process**
The selection process involves two independent tasks:
Task 1: Select 3 men from the available 7 men.
Task 2: Select 2 women from the available 5 women.

**Step 3: Apply the Combination Formula for Each Task**
Task 1 (Selecting Men): The number of ways to choose 3 men from 7 is `7C3`.
`7C3 = 7! / (3! * (7 - 3)!)`
`7C3 = 7! / (3! * 4!)`
`7C3 = (7 * 6 * 5 * 4!) / ((3 * 2 * 1) * 4!)`
`7C3 = (7 * 6 * 5) / 6`
`7C3 = 7 * 5 = 35` ways.

Task 2 (Selecting Women): The number of ways to choose 2 women from 5 is `5C2`.
`5C2 = 5! / (2! * (5 - 2)!)`
`5C2 = 5! / (2! * 3!)`
`5C2 = (5 * 4 * 3!) / ((2 * 1) * 3!)`
`5C2 = (5 * 4) / 2`
`5C2 = 20 / 2 = 10` ways.

**Step 4: Apply the Multiplication Principle**
Since both Task 1 AND Task 2 must occur to form the committee as required, we multiply the number of ways for each task.
Total Ways = (Ways to select men) * (Ways to select women)
Total Ways = `7C3 * 5C2`
Total Ways = 35 * 10
Total Ways = 350

**Step 5: State the Final Answer**
The committee can be formed in 350 ways with exactly 3 men and 2 women. This matches option (A).

## Shortcut/Tip
1.  **Selection = Combination:** If the problem involves choosing groups, teams, committees, etc., where the order of selection doesn't matter, use combinations (`nCr`).
2.  **'AND' Constraint = Multiply:** When constraints require fulfilling multiple conditions simultaneously (e.g., select 3 men AND 2 women), calculate the ways for each condition separately and multiply the results.
3.  **'OR' Constraint = Add:** If the constraint involved alternatives (e.g., committee with *at least* 4 men, meaning 4 men OR 5 men), you would calculate ways for each case and add the results.
4.  **Simplify Calculation:** Use the symmetry property `nCr = nC(n-r)` if it simplifies calculation (e.g., `10C8` is easier as `10C2`). Also, cancel factorials effectively: `7! / (3! * 4!) = (7*6*5*4!)/(3*2*1*4!) = (7*6*5)/6`.
5.  **Distractor Awareness:** Option (B) 45 is `7C3 + 5C2`, incorrectly adding instead of multiplying. Option (C) 792 is `12C5`, the total number of ways to form *any* committee of 5 from 12 people without constraints. Option (D) might arise from miscalculation or using permutations.
