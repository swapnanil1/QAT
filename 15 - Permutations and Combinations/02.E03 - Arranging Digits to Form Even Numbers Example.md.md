# Arranging Digits to Form Even Numbers Example

**Problem:**
How many 4-digit even numbers can be formed using the digits 1, 2, 3, 4, 5 without repetition?

(A) 24
(B) 48
(C) 72
(D) 120

## Solution:

This problem involves arranging a subset of distinct digits (`r=4`) from a given set (`n=5`) to form numbers, with a specific constraint (the number must be even). We apply the principles of permutations and handle constraints first, as discussed in [[15 - Permutations and Combinations/02 - Permutation (Arrangement) Formula (nPr).md|the permutation concept note]].

**Step 1: Identify n, r, and the Constraint**
Total available distinct digits (n) = {1, 2, 3, 4, 5}. So, `n=5`.
Number of digits in the number to be formed (r) = 4.
Constraint: The number must be even. This means the units digit (the last digit) must be an even number from the available set {2, 4}.

**Step 2: Handle the Constraint First (Fill the Units Place)**
The units place must be filled with either 2 or 4.
Number of ways to fill the units place = 2 ways.

**Step 3: Fill the Remaining Places**
After placing one digit in the units place, we have:
Remaining available digits = `n - 1 = 5 - 1 = 4`.
Remaining places to fill = `r - 1 = 4 - 1 = 3` (thousands, hundreds, tens places).

We need to arrange 3 digits from the remaining 4 available digits in the remaining 3 places. The number of ways to do this is a permutation: `(n-1)P(r-1)`.
Number of ways to fill the remaining 3 places = `4P3`.

**Step 4: Calculate 4P3**
Using the permutation formula `nPr = n! / (n-r)!`:
`4P3 = 4! / (4 - 3)!`
`4P3 = 4! / 1!`
`4P3 = (4 * 3 * 2 * 1) / 1`
`4P3 = 24` ways.

**Step 5: Apply the Multiplication Principle**
The total number of 4-digit even numbers is the product of the number of ways to fill the constrained units place and the number of ways to fill the remaining places.
Total Arrangements = (Ways to fill units place) * (Ways to fill remaining places)
Total Arrangements = `2 * 4P3`
Total Arrangements = 2 * 24
Total Arrangements = 48

**Step 6: State the Final Answer**
There are 48 different 4-digit even numbers that can be formed using the digits 1, 2, 3, 4, 5 without repetition. This matches option (B).

## Shortcut/Tip
1.  **Constraint First:** When dealing with permutations involving constraints on specific positions (like units digit for even/odd numbers, or starting digit), always fill the constrained position(s) first.
2.  **Track Remaining Items/Places:** After filling a constrained position, carefully update the count of available items (`n`) and remaining places (`r`) before calculating the permutations for the rest.
3.  **Multiplication Principle:** Use the multiplication principle to combine the number of ways for each step (filling constrained place * filling remaining places).
4.  **Distinct Digits:** The problem specifies "without repetition," confirming the use of standard permutation formulas where items are used at most once. If repetition were allowed, the approach would change (e.g., `5 * 5 * 5 * 2` would be the calculation).
5.  **Distractor Check:** Option (A) 24 corresponds to `4P3` only, forgetting the constraint on the units digit. Option (D) 120 corresponds to `5P4`, the total number of 4-digit numbers without the "even" constraint. Option (C) 72 doesn't directly correspond to a simple common error but might arise from miscalculation.
