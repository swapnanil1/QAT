# AP Term and Sum Example

**Problem:**

Find the sum of the first 20 terms of the arithmetic progression (AP): 3, 7, 11, 15, ...

(A) 780
(B) 800
(C) 820
(D) 840

## Solution:

This problem requires finding the sum of the first `n` terms of a given Arithmetic Progression using the standard formulas discussed in [[18 - Miscellaneous (Optional)/02 - Series and Progressions (AP, GP).md|Series and Progressions (AP, GP)]].

**Step 1:** Identify the first term (a), the common difference (d), and the number of terms (n).
   - First term, `a = 3`.
   - Common difference, `d = a_2 - a_1 = 7 - 3 = 4`. (Check: `11 - 7 = 4`, `15 - 11 = 4`).
   - Number of terms, `n = 20`.

**Step 2:** Select the appropriate formula for the sum of the first n terms of an AP.
   The formula is `S_n = n/2 * [2a + (n-1)d]`.

**Step 3:** Substitute the identified values into the formula.
   `S_20 = 20/2 * [2*3 + (20-1)*4]`

**Step 4:** Perform the calculation.
   `S_20 = 10 * [6 + (19)*4]`
   `S_20 = 10 * [6 + 76]`
   `S_20 = 10 * [82]`
   `S_20 = 820`

The sum of the first 20 terms of the given AP is 820.

This matches option (C).

## Shortcut/Tip

*   **Quick Identification:** First, confirm it's an AP by checking for a constant difference between consecutive terms. Quickly identify `a` (first term) and `d` (difference).
*   **Formula Accuracy:** Ensure you use the correct sum formula `S_n = n/2 * [2a + (n-1)d]`. Don't confuse it with the nth term formula `a_n = a + (n-1)d`.
*   **`n-1` Pitfall:** A very common error is using `n` instead of `n-1` inside the bracket. Here, `n-1 = 20-1 = 19`. Using 20 would lead to `10 * [6 + 20*4] = 10 * [6 + 80] = 860`, which is incorrect. Using 18 might lead towards option A.
*   **Calculation Order:** Follow standard order of operations (PEMDAS/BODMAS). Calculate `(n-1)*d` first, then add `2a`, then multiply by `n/2`.
*   **Distractor Check:** Option (A) 780 might arise from using `n-1=18` (calculating `10 * [6+18*4] = 10*78=780`). Options (B) and (D) likely represent general calculation errors. Double-checking the arithmetic `6 + 76 = 82` and `10 * 82 = 820` is wise.
