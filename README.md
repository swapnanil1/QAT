# Welcome to the Quantitative Aptitude Obsidian Vault! 👋

✨ This vault contains structured notes designed to help students prepare for quantitative aptitude sections in placement tests and competitive exams. ✨

The notes emphasize clarity, conciseness, exam-focused strategies, shortcuts, and common pitfalls. Use Obsidian's powerful linking and search features to navigate the concepts efficiently!

---

## Essential Plugin Recommendation 🔌

To enhance your experience, especially for visualizing certain concepts or structures, please install the **Mermaid Tools** plugin:

1.  Go to Obsidian `Settings`.
2.  Navigate to `Community plugins`.
3.  Make sure `Restricted mode` is **OFF**.
4.  Click `Browse` community plugins.
5.  Search for `Mermaid Tools`.
6.  Click `Install` and then `Enable` the plugin.

This plugin will allow you to render and interact with diagrams written using the Mermaid syntax, which might be used in some notes.

## Concepts Covered 📚

Here's a list of the main topics included in this vault:

*   🔢 **01 - Number System:** Divisibility, Factors, HCF/LCM, Remainders, Units Digit, etc.
*   📈 **02 - Percentages:** Conversions, Increase/Decrease, Successive Changes, Applications.
*   💰 **03 - Profit and Loss:** CP/SP, Profit/Loss %, Markup, Discount, Dishonesty.
*   🏦 **04 - Simple and Compound Interest:** Formulas, SI vs CI, Installments.
*   ⚖️ **05 - Ratio and Proportion:** Concepts, Combining Ratios, Applications.
*   🧪 **06 - Mixtures and Alligations:** Alligation Rule, Mixture Problems, Dilution.
*   🤝 **07 - Partnership:** Profit Sharing, Investment/Time Ratios.
*   📊 **08 - Averages:** Basic & Weighted Average, Properties, Applications.
*   👷 **09 - Time and Work:** Work Rate, LCM Method, Efficiency, Wages, MDH Formula.
*   🚰 **10 - Pipes and Cisterns:** Filling/Emptying Rates, Leakage Problems.
*   🚆 **11 - Time, Speed and Distance:** Basics, Average/Relative Speed, Trains, Boats & Streams.
*   🧮 **12 - Algebra:** Identities, Equations (Linear, Quadratic), Indices & Surds.
*   📐 **13 - Geometry:** Lines, Angles, Triangles, Quadrilaterals, Circles.
*   📏 **14 - Mensuration (2D and 3D):** Area, Perimeter, Surface Area, Volume.
*   🔄 **15 - Permutations and Combinations:** Factorials, nPr, nCr, Arrangements, Selections.
*   🎲 **16 - Probability:** Basics, Rules, Cards, Balls Problems.
*   📉 **17 - Data Interpretation (DI):** Tables, Bar/Line Graphs, Pie Charts.
*   ❓ **18 - Miscellaneous (Optional):** Logarithms, Series (AP/GP), Set Theory, Clocks & Calendars.
