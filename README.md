# Welcome to the Quantitative Aptitude Obsidian Vault! 👋

✨ This vault contains structured notes designed to help students prepare for quantitative aptitude sections in placement tests and competitive exams. ✨

The notes emphasize clarity, conciseness, exam-focused strategies, shortcuts, and common pitfalls. Use Obsidian's powerful linking and search features to navigate the concepts efficiently!

---

## Essential Plugin Recommendation 🔌

To enhance your experience, especially for visualizing certain concepts or structures, please install the **Mermaid Tools** plugin:

1.  Go to Obsidian `Settings`.
2.  Navigate to `Community plugins`.
3.  Make sure `Restricted mode` is **OFF**.
4.  Click `Browse` community plugins.
5.  Search for `Mermaid Tools`.
6.  Click `Install` and then `Enable` the plugin.

This plugin will allow you to render and interact with diagrams written using the Mermaid syntax, which might be used in some notes.
