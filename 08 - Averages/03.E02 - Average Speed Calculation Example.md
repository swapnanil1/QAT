# Average Speed Calculation Example

**Problem:**

A motorist travels a distance of 150 km at an average speed of 50 km/hr. He then travels another 100 km at an average speed of 40 km/hr. What is his average speed for the entire journey?

(A) 500/11 km/hr
(B) 45 km/hr
(C) 46 km/hr
(D) 400/9 km/hr

## Solution:

The average speed is defined as Total Distance divided by Total Time taken. It is **not** the simple average of the speeds, nor is it typically a direct weighted average using distances as weights. It relates to [[08 - Averages/03 - Weighted Average.md]] in that it can be viewed as a weighted average of speeds weighted by the *time* spent at each speed.

**Step 1: Calculate the time taken for the first part of the journey.**
Distance 1 (`d1`) = 150 km
Speed 1 (`s1`) = 50 km/hr
Time 1 (`t1`) = `d1 / s1` = 150 / 50 = 3 hours.

**Step 2: Calculate the time taken for the second part of the journey.**
Distance 2 (`d2`) = 100 km
Speed 2 (`s2`) = 40 km/hr
Time 2 (`t2`) = `d2 / s2` = 100 / 40 = 10 / 4 = 2.5 hours.

**Step 3: Calculate the total distance.**
Total Distance = `d1 + d2` = 150 km + 100 km = 250 km.

**Step 4: Calculate the total time taken.**
Total Time = `t1 + t2` = 3 hours + 2.5 hours = 5.5 hours.

**Step 5: Calculate the average speed.**
Average Speed = Total Distance / Total Time
Average Speed = 250 km / 5.5 hours
Average Speed = 250 / (11/2) = 250 * (2/11) = 500 / 11 km/hr.

The average speed for the entire journey is 500/11 km/hr. This matches option (A).

Let's check the distractors:
*   Option (B) 45 km/hr: This is the simple average of the speeds (50 + 40) / 2. This is incorrect because the time spent at each speed was different.
*   Option (C) 46 km/hr: This might result from incorrectly weighting the average by distance: `(150*50 + 100*40) / (150+100) = (7500 + 4000) / 250 = 11500 / 250 = 1150 / 25 = 46`. This is also incorrect.
*   Option (D) 400/9 km/hr: This is the harmonic mean `2 / (1/50 + 1/40) = 400/9`. This formula is only applicable when the *distances* traveled at each speed are equal, which is not the case here.

## Shortcut/Tip

1.  **Core Formula:** Always remember `Average Speed = Total Distance / Total Time`. Never take shortcuts like averaging the speeds directly unless the *time* spent at each speed is equal.
2.  **Calculate Times:** The crucial step is calculating the time taken for each segment of the journey using `Time = Distance / Speed`.
3.  **Avoid Common Traps:** Be aware of the common mistakes:
    *   Simple average of speeds (only works if times are equal).
    *   Distance-weighted average of speeds (incorrect concept for average speed).
    *   Harmonic mean of speeds (only works if distances are equal).
4.  **Weighted Average by Time:** Average speed *is* conceptually a weighted average of speeds, but the weights are the *times* spent at each speed: `Avg Speed = (t1*s1 + t2*s2) / (t1 + t2)`. Notice this simplifies: `( (d1/s1)*s1 + (d2/s2)*s2 ) / (t1 + t2) = (d1 + d2) / (t1 + t2)`, which brings us back to the fundamental definition. This understanding reinforces why time is the critical factor.
