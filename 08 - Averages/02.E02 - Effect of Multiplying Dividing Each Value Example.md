# Effect of Modifying Each Value Example

**Problem:**

The average monthly salary of 12 employees in a small firm is Rs. 15,000. Due to good performance, the company decides to give each employee a fixed bonus of Rs. 500 and also a 10% increment based on their *original* individual salaries. What is the new average monthly earning per employee?

(A) Rs. 15,500
(B) Rs. 16,500
(C) Rs. 17,050
(D) Rs. 17,000

## Solution:

This problem applies the properties of averages when each observation is modified by addition and multiplication (percentage increase), as outlined in [[08 - Averages/02 - Properties of Averages.md]].

**Method 1: Using Properties of Averages**

1.  **Initial Average:** The original average salary is `A = 15000`.
2.  **Effect of Fixed Bonus:** Each employee gets Rs. 500 added. According to the properties, if a constant value `k` (here, 500) is added to each observation, the average increases by `k`.
    Average after bonus = `A + 500 = 15000 + 500 = 15500`.
3.  **Effect of Percentage Increment:** Each employee gets a 10% increment on their *original* salary. Let the original salaries be `s1, s2, ..., s12`. The increment for each employee is `0.10 * s1`, `0.10 * s2`, etc.
    The *average* of these increments will be `(0.10*s1 + 0.10*s2 + ... + 0.10*s12) / 12`
    `= 0.10 * (s1 + s2 + ... + s12) / 12`
    `= 0.10 * (Original Average Salary)`
    Average increment = 10% of 15000 = `0.10 * 15000 = 1500`.
4.  **Calculate the New Average:** The new average is the original average plus the average increase from the bonus plus the average increase from the increment.
    New Average = Original Average + Bonus Increase + Increment Increase
    New Average = 15000 + 500 + 1500
    New Average = 17000.

**Method 2: Using Total Sum**

1.  **Calculate the initial total salary.**
    Number of employees = 12
    Average salary = 15,000
    Initial Total Salary = Average * Number = 15000 * 12 = 180,000.
2.  **Calculate the total bonus amount.**
    Bonus per employee = 500
    Total Bonus = 500 * 12 = 6,000.
3.  **Calculate the total increment amount.**
    The increment is 10% of each *original* salary. The total increment will be 10% of the *total original salary*.
    Total Increment = 10% of 180,000 = `0.10 * 180000 = 18000`.
4.  **Calculate the new total earnings.**
    New Total Earnings = Initial Total Salary + Total Bonus + Total Increment
    New Total Earnings = 180000 + 6000 + 18000 = 204000.
5.  **Calculate the new average earnings.**
    New Average = New Total Earnings / Number of Employees
    New Average = 204000 / 12
    New Average = (120000 + 84000) / 12 = 10000 + 7000 = 17000.

Both methods yield the same result: Rs. 17,000. This matches option (D).

## Shortcut/Tip

Directly apply the properties to the average value:

1.  **Start with the original average:** 15,000.
2.  **Add the constant bonus:** Since each employee gets Rs. 500, the average increases by 500. -> 15,000 + 500 = 15,500.
3.  **Add the average increment:** Since each employee gets a 10% increment on their original salary, the average salary also increases by 10% of the *original average*. 10% of 15,000 = 1,500.
4.  **Combine the effects:** New Average = Original Average + Bonus Effect + Increment Effect = 15,000 + 500 + 1,500 = 17,000.

Be careful with the wording: "10% increment based on their original individual salaries" means the average increment is 10% of the *original average*. If it were "10% increment on the new salary after bonus", the calculation would differ (10% of 15,500), leading to option (C) as a potential distractor.
