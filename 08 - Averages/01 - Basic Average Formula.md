# Basic Average Formula

**Definition:**

The average, often referred to as the arithmetic mean, provides a single value representing the central point of a dataset. It is calculated by dividing the total sum of all values (observations) in the set by the count of those values.

**Formula:**

The fundamental formula for calculating the average is:
`Average = (Sum of Observations) / (Number of Observations)`

If we denote the observations as `x1, x2, x3, ..., xn`, and the total number of observations as `n`, the formula is:
`Average (A) = (x1 + x2 + x3 + ... + xn) / n`

Alternatively, if the average and the number of observations are known, the sum of observations can be found using:
`Sum of Observations = Average * Number of Observations`

**Core Components:**

*   **Observations:** The individual data points or numerical values within a set (e.g., scores of students, temperatures, heights).
*   **Sum:** The result obtained by adding all the individual observations together.
*   **Number of Observations (Count):** The total count of data points in the set.

**Significance and Use:**

The average is a cornerstone concept in quantitative aptitude, used extensively to:
*   Summarize large datasets into a single representative number.
*   Compare different groups or datasets.
*   Serve as a basis for more complex calculations involving [[08 - Averages/03 - Weighted Average.md]], [[08 - Averages/04 - Problems on Ages, Runs, etc.md]], and problems in [[11 - Time, Speed and Distance/02 - Average Speed Concepts.md]].
