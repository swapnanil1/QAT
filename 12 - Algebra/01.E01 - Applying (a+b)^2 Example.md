# Applying (a+b)^2 Example

**Problem:**
Simplify the expression `(2x + 5y)^2`.

(A) `4x^2 + 25y^2`
(B) `4x^2 + 10xy + 25y^2`
(C) `4x^2 + 20xy + 25y^2`
(D) `2x^2 + 20xy + 5y^2`

## Solution:

This problem requires expanding the square of a binomial expression. We can use the algebraic identity `(a+b)^2 = a^2 + 2ab + b^2`, as defined in [[12 - Algebra/01 - Basic Algebraic Identities.md]].

**Step 1: Identify 'a' and 'b'**
In the given expression `(2x + 5y)^2`, compare it to the identity `(a+b)^2`:
*   `a` corresponds to `2x`
*   `b` corresponds to `5y`

**Step 2: Apply the Identity Formula**
Substitute `a = 2x` and `b = 5y` into the expansion `a^2 + 2ab + b^2`:
`(2x + 5y)^2 = (2x)^2 + 2*(2x)*(5y) + (5y)^2`

**Step 3: Simplify Each Term**
*   `(2x)^2 = 2^2 * x^2 = 4x^2`
*   `2 * (2x) * (5y) = (2 * 2 * 5) * (x * y) = 20xy`
*   `(5y)^2 = 5^2 * y^2 = 25y^2`

**Step 4: Combine the Terms**
Substitute the simplified terms back into the expanded form:
`(2x + 5y)^2 = 4x^2 + 20xy + 25y^2`

This matches option (C).

## Shortcut/Tip
1.  **Recognize the Pattern:** Immediately identify the expression as being in the form `(a+b)^2`.
2.  **Mental Calculation:**
    *   Square the first term: `(2x)^2 = 4x^2`. (Eliminates option D).
    *   Square the second term: `(5y)^2 = 25y^2`. (Matches options A, B, C).
    *   Calculate the middle term (twice the product): `2 * (2x) * (5y) = 20xy`. (Matches option C).
3.  **Common Error:** A frequent mistake is forgetting the middle term (`2ab`) and incorrectly writing `(a+b)^2` as `a^2 + b^2` (leading to option A). Always remember the middle term in binomial expansions.
