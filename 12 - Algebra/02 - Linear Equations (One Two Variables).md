# Linear Equations (One Two Variables)

---

**Introduction:**

Linear equations are algebraic equations in which each term is either a constant or the product of a constant and a single variable raised to the power of one. They represent straight-line relationships when graphed. Understanding how to solve linear equations in one and two variables is fundamental to quantitative aptitude, forming the basis for many word problems and more complex algebraic manipulations.

**Linear Equations in One Variable:**

*   **Standard Form:** `ax + b = 0`, where `x` is the variable, and `a` and `b` are constants (`a ≠ 0`). It can also appear as `ax = b` or similar rearrangements.
*   **Concept:** Represents a single point on a number line or a horizontal/vertical line on a 2D graph (e.g., `x=k` or `y=k`).
*   **Goal:** To find the specific value of the variable `x` that makes the equation true.
*   **Method:** Isolate the variable (`x`) by performing inverse operations (addition/subtraction, multiplication/division) on both sides of the equation, maintaining balance.
    *   Example: Solve `3x + 5 = 14`
        1.  Subtract 5 from both sides: `3x = 14 - 5` => `3x = 9`
        2.  Divide both sides by 3: `x = 9 / 3` => `x = 3`
*   **See Example:** [[12 - Algebra/02.E01 - Solving Linear Equation in One Variable Example.md]] (illustrates the step-by-step isolation process)

**Linear Equations in Two Variables:**

*   **Standard Form:** `ax + by = c` or `ax + by + c = 0`, where `x` and `y` are variables, and `a`, `b`, and `c` are constants (and `a`, `b` are not both zero).
*   **Concept:** Represents a straight line on a two-dimensional coordinate plane (Cartesian graph). A single linear equation in two variables has infinitely many solutions (all the points `(x, y)` lying on the line).
*   **System of Linear Equations:** To find a *unique* solution `(x, y)`, we typically need a system of two independent and consistent linear equations. This unique solution represents the point where the two lines corresponding to the equations intersect.
*   **Methods for Solving Systems of Two Linear Equations:**
    1.  **Substitution Method:**
        *   Solve one equation for one variable (e.g., solve for `y` in terms of `x`).
        *   Substitute this expression into the *other* equation.
        *   This results in a linear equation in one variable, which can be solved.
        *   Substitute the found value back into one of the original equations to find the value of the second variable.
    2.  **Elimination Method:**
        *   Multiply one or both equations by constants so that the coefficients of one variable (either `x` or `y`) are opposites (e.g., +3 and -3).
        *   Add the two modified equations together. This eliminates one variable.
        *   Solve the resulting linear equation in one variable.
        *   Substitute the found value back into one of the original equations to find the value of the second variable.
    3.  **Graphical Method (Conceptual):**
        *   Graph both lines on the same coordinate plane.
        *   The point of intersection `(x, y)` is the solution. (Less practical for precise numerical answers in exams compared to algebraic methods).
*   **See Example:** [[12 - Algebra/02.E02 - Solving System of Two Linear Equations Example.md]] (illustrates substitution or elimination methods)

**Applications:**

Linear equations are used extensively to model real-world scenarios involving:
*   Age problems
*   Mixture problems ([[06 - Mixtures and Alligations/01 - Alligation Rule Concept.md]])
*   Distance, rate, time problems ([[11 - Time, Speed and Distance/01 - Basic Formula (D=S T) and Unit Conversions.md]])
*   Cost and quantity problems
*   Geometric relationships

**General Approach:**

1.  **Identify:** Determine if you have one equation in one variable or a system of two equations in two variables.
2.  **Translate (if word problem):** Convert the word problem into mathematical equations.
3.  **Choose Method:** Select the most appropriate method (isolation, substitution, elimination).
4.  **Solve:** Carefully perform the algebraic steps.
5.  **Check:** Substitute the solution(s) back into the original equation(s) to verify correctness.
