# Solving System of Two Linear Equations Example

**Problem:**
Find the values of `x` and `y` that satisfy the following system of linear equations:
1.  `3x + 2y = 18`
2.  `5x - 3y = 11`

(A) x = 2, y = 6
(B) x = 3, y = 4.5
(C) x = 4, y = 3
(D) x = 5, y = 1.5

## Solution:

This problem requires solving a system of two linear equations with two variables. We can use either the Substitution Method or the Elimination Method, as described in [[12 - Algebra/02 - Linear Equations (One Two Variables).md]]. Let's use the Elimination Method here as the coefficients aren't simple multiples.

**Step 1: Choose a Variable to Eliminate**
Let's choose to eliminate `y`. The coefficients of `y` are +2 and -3. The least common multiple (LCM) of 2 and 3 is 6. We need to make the coefficients of `y` +6 and -6.

**Step 2: Modify the Equations**
*   Multiply Equation 1 by 3:
    `3 * (3x + 2y) = 3 * 18`
    `9x + 6y = 54` (Equation 3)
*   Multiply Equation 2 by 2:
    `2 * (5x - 3y) = 2 * 11`
    `10x - 6y = 22` (Equation 4)

**Step 3: Add the Modified Equations**
Now add Equation 3 and Equation 4. The `y` terms will cancel out:
`(9x + 6y) + (10x - 6y) = 54 + 22`
`9x + 10x + 6y - 6y = 76`
`19x = 76`

**Step 4: Solve for x**
Divide both sides by 19:
`x = 76 / 19`
`x = 4`

**Step 5: Substitute to Find y**
Substitute the value `x = 4` back into one of the original equations. Let's use Equation 1 (`3x + 2y = 18`):
`3*(4) + 2y = 18`
`12 + 2y = 18`
Subtract 12 from both sides:
`2y = 18 - 12`
`2y = 6`
Divide both sides by 2:
`y = 6 / 2`
`y = 3`

**Step 6: State the Solution**
The solution is `x = 4` and `y = 3`. This matches option (C).

*(Self-check: Substitute x=4, y=3 into the *other* original equation (Equation 2): `5*(4) - 3*(3) = 20 - 9 = 11`. This matches the right side, confirming the solution.)*

## Shortcut/Tip
1.  **Choose Elimination Wisely:** Decide whether to eliminate `x` or `y`. Often, it's easier to eliminate the variable whose coefficients have a smaller LCM. (Here, LCM for x coeffs 3, 5 is 15; LCM for y coeffs 2, 3 is 6. Eliminating `y` was slightly easier).
2.  **Substitution Alternative:** You could solve one equation for one variable (e.g., solve Eq1 for `y`: `y = (18 - 3x) / 2`) and substitute into Eq2. This might involve fractions, making elimination preferable sometimes.
3.  **Check Your Solution:** Always substitute the found values (`x=4, y=3`) back into *both* original equations (or at least the one you didn't use for back-substitution) to ensure accuracy.
4.  **MCQ Option Testing:** For systems of equations, testing options can be viable but potentially slower than direct solving. Substitute the (x, y) pair from an option into *both* equations. Only the correct option will satisfy both.
