# Simplifying Surds Example

**Problem:**
Simplify the expression: `( sqrt(48) + sqrt(75) ) / sqrt(12)`

(A) `9 / (2*sqrt(3))`
(B) `4.5`
(C) `9*sqrt(3)`
(D) `4.5 * sqrt(3)`

## Solution:

This problem involves simplifying an expression containing surds (square roots). We need to simplify each surd, perform addition, and then division, potentially requiring rationalization, based on the rules in [[12 - Algebra/04 - Indices and Surds.md]].

**Step 1: Simplify each surd individually**
*   `sqrt(48)`: Find the largest perfect square factor of 48. `48 = 16 * 3`.
    `sqrt(48) = sqrt(16 * 3) = sqrt(16) * sqrt(3) = 4*sqrt(3)`
*   `sqrt(75)`: Find the largest perfect square factor of 75. `75 = 25 * 3`.
    `sqrt(75) = sqrt(25 * 3) = sqrt(25) * sqrt(3) = 5*sqrt(3)`
*   `sqrt(12)`: Find the largest perfect square factor of 12. `12 = 4 * 3`.
    `sqrt(12) = sqrt(4 * 3) = sqrt(4) * sqrt(3) = 2*sqrt(3)`

**Step 2: Substitute the simplified surds back into the expression**
Expression = `( 4*sqrt(3) + 5*sqrt(3) ) / ( 2*sqrt(3) )`

**Step 3: Perform addition in the numerator**
The surds in the numerator are like surds (both are `sqrt(3)`). Add their coefficients:
Numerator = `(4 + 5) * sqrt(3) = 9*sqrt(3)`

**Step 4: Perform the division**
Expression = `( 9*sqrt(3) ) / ( 2*sqrt(3) )`

We can cancel the common factor `sqrt(3)` from the numerator and the denominator.
Expression = 9 / 2

**Step 5: Convert to decimal (optional, based on options)**
Expression = 9 / 2 = 4.5

The simplified value is 4.5. This matches option (B).

*(Note: Rationalization was not needed here because the surd term cancelled out completely. If the denominator had been, for example, `2*sqrt(5)`, we would have needed to rationalize).*

## Shortcut/Tip
1.  **Simplify First:** Always simplify each surd to its simplest form (`a*sqrt(b)` where `b` has no perfect square factors) *before* performing operations like addition or division.
2.  **Look for Like Surds:** Simplification often reveals like surds (same root and radicand), allowing for addition/subtraction of coefficients.
3.  **Cancel Common Factors:** After simplifying and combining, look for common factors (both numerical and surd factors like `sqrt(3)` in this case) that can be cancelled between the numerator and denominator.
4.  **Rationalization (if needed):** If a surd remains in the denominator after simplification, rationalize by multiplying the numerator and denominator by the appropriate term (often the conjugate if the denominator is a binomial). Example: To rationalize `1 / (2 + sqrt(3))`, multiply by `(2 - sqrt(3)) / (2 - sqrt(3))`.
5.  **Check Options:** Sometimes the options guide whether you need to rationalize fully or if intermediate forms match. Option (A) `9 / (2*sqrt(3))` is what you get before cancelling `sqrt(3)` and is incorrect as it's not fully simplified.
