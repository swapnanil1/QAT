# Laws of Indices Application Example

**Problem:**
Simplify the expression: `( (3x^-2 * y^3)^2 ) / ( 9x^-5 * y^4 )`

(A) `x * y^2`
(B) `y^2 / x`
(C) `x / y^2`
(D) `9x * y^2`

## Solution:

This problem requires simplifying an algebraic expression involving indices (exponents) using the laws of indices detailed in [[12 - Algebra/04 - Indices and Surds.md]]. We need to handle powers of products, powers of powers, negative exponents, and division.

**Step 1: Simplify the Numerator**
Numerator = `(3x^-2 * y^3)^2`
Apply the Power of a Product Rule `(a * b)^m = a^m * b^m`:
Numerator = `3^2 * (x^-2)^2 * (y^3)^2`

Now apply the Power of a Power Rule `(a^m)^n = a^(m*n)`:
Numerator = `9 * x^(-2 * 2) * y^(3 * 2)`
Numerator = `9 * x^-4 * y^6`

**Step 2: Simplify the Denominator**
The denominator is already simplified: `9x^-5 * y^4`

**Step 3: Divide the Numerator by the Denominator**
Expression = `(9 * x^-4 * y^6) / (9 * x^-5 * y^4)`

Group terms with the same base:
Expression = `(9 / 9) * (x^-4 / x^-5) * (y^6 / y^4)`

**Step 4: Apply the Quotient Rule**
Apply the Quotient Rule `a^m / a^n = a^(m-n)` for each base:
*   For the coefficient: 9 / 9 = 1
*   For base `x`: `x^-4 / x^-5 = x^(-4 - (-5)) = x^(-4 + 5) = x^1 = x`
*   For base `y`: `y^6 / y^4 = y^(6 - 4) = y^2`

**Step 5: Combine the Results**
Expression = `1 * x * y^2`
Expression = `x * y^2`

The simplified expression is `x * y^2`. This matches option (A).

## Shortcut/Tip
1.  **Handle Numerator/Denominator Separately:** Simplify the numerator and denominator fully before attempting the division. This reduces complexity.
2.  **Power Rules First:** Apply the power rules (`(a*b)^m`, `(a^m)^n`) to remove parentheses before applying quotient rules.
3.  **Negative Exponent Care:** Be meticulous when subtracting negative exponents using the quotient rule (`m - (-n) = m + n`). Errors here are common (e.g., calculating `-4 - 5` instead of `-4 - (-5)`).
4.  **Coefficient Handling:** Treat numerical coefficients separately (`9/9 = 1`). Don't forget this step (leads to error like option D).
5.  **Step-by-Step:** Even if quick, mentally follow the steps: Power rules -> Simplify numerator/denominator -> Quotient rule for each base.
