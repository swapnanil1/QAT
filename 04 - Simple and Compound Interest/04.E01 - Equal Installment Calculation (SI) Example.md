## Equal Installment Calculation (SI) Example

Parent Concept: [[04 - Simple and Compound Interest/04 - Installments.md]]

---

**Problem:**

What annual installment will discharge a debt of Rs. 1092 due in 3 years at 12% simple interest?

**Options:**
(A) Rs. 300
(B) Rs. 350
(C) Rs. 375
(D) Rs. 325

**Solution:**

This problem requires calculating the equal annual installment `X` needed to clear a debt `D` due in the future, considering simple interest earned by the installments paid early.

**1. Identify the given information:**
*   Debt due (D) = Rs. 1092
*   Time (T) = 3 years
*   Rate (R) = 12% p.a. (Simple Interest)
*   Annual Installment (X) = ?

**2. Recall the formula for SI installments (clearing future debt):**

The equal Annual Installment `X` required to clear a debt `D` due in `T` years at `R`% p.a. simple interest is:
`X = (100 * D) / [ 100*T + (R * T * (T-1)) / 2 ]`

**3. Substitute the known values into the formula:**

X = (100 * 1092) / [ 100*3 + (12 * 3 * (3-1)) / 2 ]
X = 109200 / [ 300 + (12 * 3 * 2) / 2 ]
X = 109200 / [ 300 + (72 / 2) ]
X = 109200 / [ 300 + 36 ]
X = 109200 / 336

**4. Calculate the value of X:**

Divide 109200 by 336.
Let's simplify by dividing both by common factors.
Divide by 2: 54600 / 168
Divide by 2: 27300 / 84
Divide by 2: 13650 / 42
Divide by 2: 6825 / 21
Divide by 3: 2275 / 7
Now divide 2275 by 7:
2275 / 7 = 325

So, X = 325.

**Conceptual Check (Optional):**
*   Installment 1 (paid after 1 yr) earns SI for 2 yrs: Value at end = `X + (X*12*2)/100 = X * (1 + 24/100) = 1.24X`
*   Installment 2 (paid after 2 yrs) earns SI for 1 yr: Value at end = `X + (X*12*1)/100 = X * (1 + 12/100) = 1.12X`
*   Installment 3 (paid after 3 yrs) earns SI for 0 yrs: Value at end = `X`
*   Total value = 1.24X + 1.12X + 1X = 3.36X
*   This total value must equal the debt D: `3.36X = 1092`
*   X = 1092 / 3.36 = 109200 / 336 = 325. (Matches the formula result)

**Answer:**

The required annual installment is Rs. 325.
Correct Option: **(D)**

## Shortcut/Tip

*   **Memorize the Formula:** The formula `X = (100 * D) / [ 100*T + (R * T * (T-1)) / 2 ]` is the quickest way for this specific type of SI installment problem (clearing a future debt).
*   **Denominator Calculation:** Calculate the denominator `[ 100*T + (R * T * (T-1)) / 2 ]` carefully first. Here: 300 + (12 * 3 * 2) / 2 = 300 + 36 = 336.
*   **Simplify Division:** When dividing `109200 / 336`, look for common factors (like 2, 3, 4, 6, 7, 12) to simplify the fraction before performing long division. Notice 336 ends in 6, 1092 ends in 2 - both even. Sum of digits of 336 is 12 (divisible by 3), sum of digits of 1092 is 12 (divisible by 3). So both are divisible by 6. Simplify progressively.
