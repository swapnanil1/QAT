## Equal Installment Calculation (CI) Example

#quant #simple_and_compound_interest #compound_interest #installments #emi #example #formula

Parent Concept: [[04 - Simple and Compound Interest/04 - Installments.md]]

---

**Problem:**

A loan of Rs. 21,000 is to be repaid in two equal annual installments. If the rate of interest is 10% per annum, compounded annually, find the value of each installment.

**Options:**
(A) Rs. 12,600
(B) Rs. 11,000
(C) Rs. 12,100
(D) Rs. 12,705

**Solution:**

This problem involves calculating the equal installment required to repay a loan taken now, using compound interest principles.

**1. Identify the given information:**
*   Principal Loan Amount (P) = Rs. 21,000
*   Number of installments (T) = 2
*   Rate of Interest (R) = 10% p.a., compounded annually.
*   Value of each installment (X) = ?

**2. Determine the rate per installment period (r):**
Since the compounding is annual and installments are annual, the rate per period `r` is the annual rate converted to a decimal.
`r = R / 100`
r = 10 / 100 = 0.1

**3. Recall the formula for CI installments (repaying current loan):**

The formula relating Principal (P), Installment (X), rate per period (r), and number of periods (T) is:
`P = X * [ (1 - (1+r)^-T) / r ]`

Or rearranged to find X:
`X = P * [ (r * (1+r)^T) / ((1+r)^T - 1) ]`

**4. Substitute the known values into the formula:**

Using the second form for X:
P = 21000, r = 0.1, T = 2.
`(1+r) = 1 + 0.1 = 1.1`
`(1+r)^T = (1.1)^2 = 1.21`

`X = 21000 * [ (0.1 * 1.21) / (1.21 - 1) ]`
X = 21000 * [ 0.121 / 0.21 ]
X = 21000 * (121 / 210)  *(Multiply numerator and denominator by 1000 to remove decimals)*

**5. Calculate the value of X:**

X = 21000 * (121 / 210)
Simplify the calculation:
X = (21000 / 210) * 121
X = 100 * 121
X = 12100

**Alternative Calculation using Present Value concept:**
Let X be the installment.
`P = PV(Installment 1) + PV(Installment 2)`
`P = [ X / (1+r)^1 ] + [ X / (1+r)^2 ]`
21000 = [ X / (1.1) ] + [ X / (1.1)^2 ]
21000 = [ X / 1.1 ] + [ X / 1.21 ]
Multiply by 1.21 to clear denominators:
21000 * 1.21 = (X / 1.1) * 1.21 + (X / 1.21) * 1.21
25410 = X * (1.21 / 1.1) + X
25410 = X * 1.1 + X
25410 = 1.1X + 1X
25410 = 2.1X
X = 25410 / 2.1
X = 254100 / 21
X = 12100

**Answer:**

The value of each annual installment is Rs. 12,100.
Correct Option: **(C)**

## Shortcut/Tip

*   **Formula is Key:** The CI installment formula `X = P * [ (r * (1+r)^T) / ((1+r)^T - 1) ]` is essential. Direct application is usually fastest.
*   **Fractional Calculation:** Convert `r` and `1+r` to fractions early if it simplifies calculations: `r = 1/10`, `1+r = 11/10`.
    `X = 21000 * [ ((1/10) * (11/10)^2) / ((11/10)^2 - 1) ]`
    `X = 21000 * [ ((1/10) * (121/100)) / (121/100 - 1) ]`
    `X = 21000 * [ (121/1000) / (21/100) ]`
    `X = 21000 * (121/1000) * (100/21)`
    `X = (21000/21) * (121/10) = 1000 * (121/10) = 100 * 121 = 12100`. This avoids decimal calculations.
*   **Elimination:** The total amount paid (`X * T`) will always be more than the principal `P` plus the simple interest `P*r*T` (unless T=1).
    *   Total payment = X * 2.
    *   P + SI = 21000 + (21000 * 0.1 * 2) = 21000 + 4200 = 25200.
    *   So, 2X must be slightly greater than 25200. X must be slightly greater than 12600. *Wait*, this logic is flawed for installments because principal reduces.
*   **Revised Elimination:** Each installment `X` must be greater than the simple interest for the first period (`P*r = 21000*0.1 = 2100`) plus the principal part repaid in the first period. Also, `X` must be greater than `P/T = 21000/2 = 10500`. The total amount paid `X*T` must be greater than the final amount if paid in lump sum `P*(1+r)^T = 21000 * 1.21 = 25410`. So `2X > 25410` => `X > 12705`. *Wait, this is also wrong*. The total value of installments' present values equals P. Let's stick to the formula or PV method. The total amount paid will be 12100 * 2 = 24200. This is less than the final compounded amount 25410, which makes sense.
*   **Key Check:** The installment X must be such that its present value sums to P. `X/(1.1) + X/(1.1)^2 = 21000`. Test Option C (12100): `12100/1.1 + 12100/1.21 = 11000 + 10000 = 21000`. This matches P, confirming the answer.
