# Reading Table Data Example

**Problem:**

The table below shows the student enrollment numbers for different engineering courses at a college for the years 2022 and 2023.

| Course        | 2022 Enrollment | 2023 Enrollment |
| :------------ | :-------------- | :-------------- |
| Computer Sci. | 150             | 180             |
| Electronics   | 120             | 110             |
| Mechanical    | 100             | 125             |
| Civil         | 90              | 95              |

What was the student enrollment number for the Mechanical course in the year 2023?

(A) 100
(B) 180
(C) 125
(D) 110

## Solution:

This problem requires accurately reading a specific data point from the provided table, applying the basic principles outlined in the [[17 - Data Interpretation (DI)/01 - Tables Interpretation.md|Tables Interpretation concept]].

**Step 1:** Identify the row corresponding to the required course. The question asks for the "Mechanical" course. Locate the row labelled "Mechanical" in the first column of the table.

**Step 2:** Identify the column corresponding to the required year. The question asks for the year "2023". Locate the column header labelled "2023 Enrollment".

**Step 3:** Find the value at the intersection of the identified row and column. The cell where the "Mechanical" row intersects the "2023 Enrollment" column contains the value 125.

This value represents the student enrollment for the Mechanical course in 2023.

This matches option (C).

## Shortcut/Tip

*   **Keyword Focus:** Quickly scan the question for the key identifiers: "Mechanical" and "2023". This immediately tells you which row and column to target.
*   **Grid Location:** Think of the table as a grid. Locate the "Mechanical" row and the "2023 Enrollment" column. The answer is the value where they intersect.
*   **Common Pitfalls:**
    *   **Wrong Year/Course:** Accidentally reading the value for 2022 (100 - matches option A) or reading the value for a different course in 2023 (e.g., Computer Sci. is 180 - matches option B, Electronics is 110 - matches option D).
    *   **Ignoring Headers:** Failing to correctly match the row/column labels with the question's requirements.
*   **Distractor Check:** Notice how the incorrect options (A, B, D) correspond to other values present in the table, specifically targeting the common pitfalls mentioned above. Recognizing this pattern helps confirm you've located the *correct* intersection.
*   **Physical Tracing:** Use your finger or mouse pointer to trace the specific row and column until they meet. This simple physical action minimizes the chance of your eyes drifting to an adjacent cell.
